# 🟦 1) **FastAPI WebSocket 서버 만들기 (영상/데이터 전송)**

이 서버는 클라이언트가 접속하면  
- 주기적으로 이미지(또는 데이터)를 WebSocket으로 전송하는 예제야.

```python
# server.py
import cv2
import base64
import asyncio
from fastapi import FastAPI, WebSocket
from fastapi.responses import HTMLResponse
import uvicorn

app = FastAPI()

@app.websocket("/detect_stream")
async def detect_stream(websocket: WebSocket):
    await websocket.accept()

    cap = cv2.VideoCapture(0)  # 웹캠 사용 (드론 스트림으로 교체 가능)

    while True:
        ret, frame = cap.read()
        if not ret:
            continue

        # JPEG로 인코딩
        _, buffer = cv2.imencode(".jpg", frame)
        jpg_as_text = base64.b64encode(buffer).decode("utf-8")

        # WebSocket으로 전송
        await websocket.send_text(jpg_as_text)

        await asyncio.sleep(0.03)  # 약 30fps

if __name__ == "__main__":
    uvicorn.run("server:app", host="0.0.0.0", port=8000)
```

✔ `/detect_stream` 경로로 WebSocket 연결  
✔ 웹캠 프레임을 JPEG → base64로 변환해 전송  
✔ 드론 RTSP를 쓰고 싶으면 `cv2.VideoCapture("rtsp://...")`로 변경하면 됨

# 🟩 2) **Python에서 WebSocket으로 영상/데이터 받기**

FastAPI 서버에서 보낸 base64 JPEG를 받아서  
OpenCV로 디코딩 후 화면에 표시하는 코드야.

```python
# client_python.py
import cv2
import base64
import numpy as np
import asyncio
import websockets

async def receive_stream():
    uri = "ws://localhost:8000/detect_stream"

    async with websockets.connect(uri) as websocket:
        while True:
            data = await websocket.recv()

            # base64 → numpy 배열
            img_data = base64.b64decode(data)
            np_arr = np.frombuffer(img_data, np.uint8)
            frame = cv2.imdecode(np_arr, cv2.IMREAD_COLOR)

            cv2.imshow("WebSocket Stream", frame)
            if cv2.waitKey(1) == 27:
                break

asyncio.run(receive_stream())
```

✔ WebSocket으로 base64 문자열 수신  
✔ OpenCV로 디코딩  
✔ 실시간 영상 표시

# 🟧 3) **JavaScript에서 WebSocket 연결하여 영상 표시**

브라우저에서 WebSocket으로 영상 스트림을 받아  
HTML `<img>` 태그에 표시하는 예제야.

```html
<!-- client_js.html -->
<!DOCTYPE html>
<html>
<body>
    <h2>WebSocket Video Stream</h2>
    <img id="video" width="640" />

    <script>
        const ws = new WebSocket("ws://localhost:8000/detect_stream");
        const img = document.getElementById("video");

        ws.onmessage = (event) => {
            img.src = "data:image/jpeg;base64," + event.data;
        };
    </script>
</body>
</html>
```

✔ WebSocket으로 base64 JPEG 수신  
✔ `<img>` 태그에 바로 표시  
✔ 브라우저에서 실시간 스트리밍 가능
