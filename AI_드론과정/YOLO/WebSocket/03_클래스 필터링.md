1. **클래스 이름까지 붙이기 (COCO names)**  
2. **특정 클래스만 필터링해서 보내기 (예: 사람, 자동차만)**

## 1. 클래스 이름까지 붙이기 (COCO names 포함)

`ultralytics.YOLO` 모델은 `model.names`에 클래스 이름을 가지고 있어.  
이를 이용해서 `cls` 인덱스를 사람이 읽을 수 있는 이름으로 바꿔서 보내면 된다.

### 🔹 FastAPI + YOLO 서버 (클래스 이름 포함)

```python
# server_yolo_names.py
import cv2
import base64
import asyncio
import json
from fastapi import FastAPI, WebSocket
import uvicorn
from ultralytics import YOLO

app = FastAPI()
model = YOLO("yolov8n.pt")
CLASS_NAMES = model.names  # 예: {0: 'person', 1: 'bicycle', ...}

@app.websocket("/detect_stream")
async def detect_stream(websocket: WebSocket):
    await websocket.accept()

    cap = cv2.VideoCapture(0)  # 드론 RTSP로 교체 가능

    while True:
        ret, frame = cap.read()
        if not ret:
            continue

        results = model(frame, verbose=False)[0]

        boxes_data = []
        for box in results.boxes:
            x1, y1, x2, y2 = box.xyxy[0].tolist()
            conf = float(box.conf[0])
            cls = int(box.cls[0])
            cls_name = CLASS_NAMES.get(cls, "unknown")

            boxes_data.append({
                "x1": x1,
                "y1": y1,
                "x2": x2,
                "y2": y2,
                "conf": conf,
                "cls": cls,
                "cls_name": cls_name
            })

            # 시각화용 박스 + 라벨
            cv2.rectangle(
                frame,
                (int(x1), int(y1)),
                (int(x2), int(y2)),
                (0, 255, 0),
                2
            )
            cv2.putText(
                frame,
                f"{cls_name} {conf:.2f}",
                (int(x1), int(y1) - 5),
                cv2.FONT_HERSHEY_SIMPLEX,
                0.5,
                (0, 255, 0),
                1
            )

        _, buffer = cv2.imencode(".jpg", frame)
        jpg_as_text = base64.b64encode(buffer).decode("utf-8")

        payload = {
            "image": jpg_as_text,
            "boxes": boxes_data
        }

        await websocket.send_text(json.dumps(payload))
        await asyncio.sleep(0.03)

if __name__ == "__main__":
    uvicorn.run("server_yolo_names:app", host="0.0.0.0", port=8000)
```

이제 클라이언트는 `cls_name`까지 받아서 바로 UI에 표시할 수 있다.

## 2. 특정 클래스만 필터링해서 보내기 (예: 사람, 자동차만)

COCO 기준으로  
- person → `"person"`  
- car → `"car"`  

이 둘만 필터링해서 보내고 싶다면, 서버에서 `cls_name` 기준으로 필터링하면 된다.

### 🔹 사람/자동차만 필터링

```python
TARGET_CLASSES = {"person", "car"}  # 원하는 클래스만

@app.websocket("/detect_stream")
async def detect_stream(websocket: WebSocket):
    await websocket.accept()
    cap = cv2.VideoCapture(0)

    while True:
        ret, frame = cap.read()

            cls = int(box.cls[0])
            cls_name = CLASS_NAMES.get(cls, "unknown")

            # 여기서 필터링
            if cls_name not in TARGET_CLASSES:
                continue

            boxes_data.append({
                "x1": x1,
                "y1": y1,
                "x2": x2,
                "y2": y2,
                "conf": conf,

                "cls_name": cls_name

                frame,
                (int(x1), int(y1)),
                (int(x2), int(y2)),
                (0, 255, 0),
                2
            )
            cv2.putText(
                frame,
                f"{cls_name} {conf:.2f}",
                (int(x1), int(y1) - 5),
                cv2.FONT_HERSHEY_SIMPLEX,
                0.5,
                (0, 255, 0),
                1
            )

        _, buffer = cv2.imencode(".jpg", frame)
        jpg_as_text = base64.b64encode(buffer).decode("utf-8")

            "image": jpg_as_text,
            "boxes": boxes_data
        }

        await asyncio.sleep(0.03)
```

이제 WebSocket으로는 **사람/자동차에 대한 박스만** 전달된다.

## 3. 박스만 WebSocket으로, 이미지는 RTSP/WebRTC로 따로 보내는 구조

이건 구조적으로 한 단계 업그레이드야.

### 🎯 목표 구조

- **영상 스트림**:  
  - RTSP 또는 WebRTC로 전송 (지연 최소화, 대역폭 효율)  
- **YOLO 감지 결과(박스 정보만)**:  
  - WebSocket(JSON)으로 전송  

클라이언트(브라우저 또는 앱)는  
- 영상은 RTSP/WebRTC 플레이어로 재생  
- 박스는 WebSocket으로 받아서 오버레이로 그림

### 🔹 서버 설계 개념

1. **YOLO 서버 입력**:  
   - RTSP/드론 스트림을 서버에서 받아서 YOLO 추론  
2. **RTSP/WebRTC 서버**:  
   - 원본 또는 YOLO가 그려지지 않은 영상만 전송  
3. **WebSocket 서버**:  
   - 프레임마다 박스 정보만 JSON으로 전송  

### 🔹 FastAPI WebSocket 서버 (박스만 전송)

```python
# server_yolo_boxes_only.py
import cv2
import asyncio
import json
from fastapi import FastAPI, WebSocket
import uvicorn
from ultralytics import YOLO

app = FastAPI()
model = YOLO("yolov8n.pt")
CLASS_NAMES = model.names

RTSP_URL = "rtsp://..."  # 드론/카메라 스트림

@app.websocket("/detect_boxes")
async def detect_boxes(websocket: WebSocket):
    await websocket.accept()

    cap = cv2.VideoCapture(RTSP_URL)

    while True:
        ret, frame = cap.read()
        if not ret:
            continue

        results = model(frame, verbose=False)[0]

        boxes_data = []
        for box in results.boxes:
            x1, y1, x2, y2 = box.xyxy[0].tolist()
            conf = float(box.conf[0])
            cls = int(box.cls[0])
            cls_name = CLASS_NAMES.get(cls, "unknown")

            boxes_data.append({
                "x1": x1,
                "y1": y1,
                "x2": x2,
                "y2": y2,
                "conf": conf,
                "cls": cls,
                "cls_name": cls_name
            })

        payload = {
            "boxes": boxes_data
        }

        await websocket.send_text(json.dumps(payload))
        await asyncio.sleep(0.03)

if __name__ == "__main__":
    uvicorn.run("server_yolo_boxes_only:app", host="0.0.0.0", port=8001)
```

여기서는 **이미지를 전혀 보내지 않고, 박스 정보만 전송**한다.

### 🔹 브라우저 쪽 구조 예시

1. **영상 재생**  
   - `<video>` 태그 + RTSP → HLS/WebRTC 변환 플레이어  
   - 예: hls.js, WebRTC 플레이어 등

2. **박스 오버레이**  
   - `<canvas>`를 `<video>` 위에 겹쳐서 그림  
   - WebSocket으로 받은 박스 좌표를 캔버스에 그리기

간단한 구조 예시(개념):

```html
<video id="video" ...></video>
<canvas id="overlay"></canvas>

<script>
  const ws = new WebSocket("ws://localhost:8001/detect_boxes");
  const canvas = document.getElementById("overlay");
  const ctx = canvas.getContext("2d");

  ws.onmessage = (event) => {
      const payload = JSON.parse(event.data);
      const boxes = payload.boxes;

      // 캔버스 초기화
      ctx.clearRect(0, 0, canvas.width, canvas.height);

      boxes.forEach(b => {
          ctx.strokeStyle = "lime";
          ctx.lineWidth = 2;
          ctx.strokeRect(b.x1, b.y1, b.x2 - b.x1, b.y2 - b.y1);

          ctx.fillStyle = "lime";
          ctx.fillText(b.cls_name + " " + b.conf.toFixed(2), b.x1, b.y1 - 5);
      });
  };
</script>
```

실제 구현에서는  
- 비디오 해상도와 캔버스 해상도 동기화  
- RTSP → HLS/WebRTC 변환 서버(예: GStreamer, FFmpeg, Janus, mediasoup 등)  
이 추가로 필요하지만, **아키텍처 개념은 이렇다**고 보면 된다.

## 정리하면

1. **클래스 이름까지 붙이기**  
   - `model.names`를 사용해서 `cls_name` 추가  
2. **특정 클래스만 필터링**  
   - `TARGET_CLASSES` 집합으로 필터링  
3. **박스만 WebSocket, 영상은 RTSP/WebRTC**  
   - YOLO 서버는 RTSP 입력 → 박스만 WebSocket으로 전송  
   - 클라이언트는 영상 플레이어 + WebSocket 박스 오버레이 조합
