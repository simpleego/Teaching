좋습니다. **class_id 기반 + class_name 기반을 동시에 지원**하도록 바꾸겠습니다.
원칙은 이렇습니다.

* 프론트는 사용자가 **이름(person, car …)** 으로 선택
* 서버로는 (권장) **class_names 배열**을 보내고, 서버가 내부적으로 **id로 매핑**해서 필터 set을 구성
* **id와 name을 동시에 보내도 됨** (혼합 지원)
* 빈 선택/`null`이면 전체로 리셋

아래는 **서버(web_server_stream.py) 수정** + **프론트(App.svelte) 수정**입니다.

# 1) 서버 수정: `set_filter`가 `class_ids` + `class_names` 모두 처리

## 변경점

* `/classes`는 그대로 사용(프론트는 여기서 id↔name을 받음)
* WS 메시지:

  * `{type:"set_filter", class_ids:[...], class_names:["person","car"]}`
  * `class_ids`만 / `class_names`만 / 둘 다 → 모두 처리
* 서버에서 `name -> id` 매핑 구축 (`name_to_id`)

아래는 **`detect_stream` 함수 내부와 관련 부분만 교체/추가**하면 됩니다.
(헷갈리지 않게 “전체 교체 가능한 블록”으로 드립니다.)

### ✅ `detect_stream` 함수 교체용 코드

```python
@app.websocket("/detect_stream")
async def detect_stream(ws: WebSocket):
    await ws.accept()
    async with _ws_lock:
        _ws_clients.add(ws)
        _ws_filters[ws] = None  # 기본: 전체 클래스

    # name->id 매핑 (대/소문자 민감도 이슈를 줄이기 위해 lower도 같이 지원)
    name_to_id = {}
    for k, v in model.names.items():
        name_to_id[str(v)] = int(k)
        name_to_id[str(v).lower()] = int(k)

    await ws.send_json({
        "type": "hello",
        "ts": time.time(),
        "filter": None,
        "hint": "Send {type:'set_filter', class_ids:[...]} or {class_names:[...]} (or both). Use null/[] to reset(all)."
    })

    try:
        while True:
            msg = await ws.receive_json()
            if not isinstance(msg, dict):
                continue

            if msg.get("type") != "set_filter":
                continue

            raw_ids = msg.get("class_ids", None)
            raw_names = msg.get("class_names", None)

            # 리셋 규칙:
            # - class_ids가 null/[] 이고 class_names도 null/[] 이면 전체 리셋
            def _is_empty(x):
                return x is None or (isinstance(x, list) and len(x) == 0)

            if _is_empty(raw_ids) and _is_empty(raw_names):
                async with _ws_lock:
                    _ws_filters[ws] = None
                await ws.send_json({"type": "filter_ack", "ok": True, "filter": None, "ts": time.time()})
                continue

            ids: Set[int] = set()

            # 1) class_ids 처리
            if raw_ids is not None:
                if not isinstance(raw_ids, list):
                    await ws.send_json({"type": "filter_ack", "ok": False, "detail": "class_ids must be a list", "ts": time.time()})
                    continue
                try:
                    ids.update(int(x) for x in raw_ids)
                except Exception:
                    await ws.send_json({"type": "filter_ack", "ok": False, "detail": "class_ids must be int list", "ts": time.time()})
                    continue

            # 2) class_names 처리
            unknown_names = []
            if raw_names is not None:
                if not isinstance(raw_names, list):
                    await ws.send_json({"type": "filter_ack", "ok": False, "detail": "class_names must be a list", "ts": time.time()})
                    continue

                for nm in raw_names:
                    if nm is None:
                        continue
                    key = str(nm)
                    cid = name_to_id.get(key)
                    if cid is None:
                        cid = name_to_id.get(key.lower())
                    if cid is None:
                        unknown_names.append(key)
                    else:
                        ids.add(int(cid))

            # 유효 id만
            valid_ids = set(int(k) for k in model.names.keys())
            ids = ids.intersection(valid_ids)

            # 만약 전부 무효면(unknown만 있거나) → 필터는 "빈 set"이 되어 아무것도 안 보임.
            # 보통은 리셋이 더 친절하지만, 여기선 사용자가 잘못 입력한 경우를 드러내기 위해 빈 set 유지.
            async with _ws_lock:
                _ws_filters[ws] = ids

            await ws.send_json({
                "type": "filter_ack",
                "ok": True,
                "filter": sorted(list(ids)),
                "unknown_names": unknown_names,
                "ts": time.time()
            })

    except WebSocketDisconnect:
        pass
    finally:
        async with _ws_lock:
            _ws_clients.discard(ws)
            _ws_filters.pop(ws, None)
```

> ✅ inference_loop는 수정할 필요 없습니다. `_ws_filters[ws]`가 set이면 그대로 필터링합니다.
> (현재는 id 기반으로 필터링하므로, name으로 선택해도 서버가 id로 바꿔서 저장합니다.)

# 2) 프론트 수정: “클래스 이름으로” 선택해서 전송 (id는 optional)

UI는 그대로 `<select multiple>`를 쓰되,

* option value를 `name`으로 바꿈
* 서버로는 `class_names`를 보내도록 변경
* (원하면) id도 같이 보낼 수 있게 name→id 맵을 사용

아래는 **App.svelte 수정본**(핵심 부분만)입니다.

### ✅ App.svelte 전체 교체 버전 (권장)

```svelte
<script>
  import { onMount } from "svelte";

  const apiBase = "http://localhost:8000";
  const wsUrl = "ws://localhost:8000/detect_stream";

  let liveImg;
  let canvas;
  let ctx;

  let status = "disconnected";
  let lastMsg = null;

  // classes: [{id, name}]
  let classes = [];
  let selectedNames = []; // ["person","car",...]

  // name -> id 매핑(옵션: id도 함께 보내고 싶을 때 사용)
  let nameToId = new Map();

  let ws = null;

  function resizeCanvasToImage() {
    if (!liveImg || !canvas) return;
    canvas.width = liveImg.clientWidth;
    canvas.height = liveImg.clientHeight;
  }

  function drawBoxes(msg) {
    if (!ctx || !liveImg) return;
    if (msg.type !== "detections") return;

    resizeCanvasToImage();

    const iw = msg.image.width;
    const ih = msg.image.height;
    const cw = canvas.width;
    const ch = canvas.height;
    const sx = cw / iw;
    const sy = ch / ih;

    ctx.clearRect(0, 0, cw, ch);
    ctx.lineWidth = 2;
    ctx.font = "14px sans-serif";

    for (const d of msg.detections) {
      const [x1, y1, x2, y2] = d.bbox_xyxy;
      const rx1 = x1 * sx, ry1 = y1 * sy;
      const rw = (x2 - x1) * sx, rh = (y2 - y1) * sy;

      ctx.strokeStyle = "lime";
      ctx.strokeRect(rx1, ry1, rw, rh);

      const label = `${d.class_name} ${d.confidence.toFixed(2)}`;
      ctx.fillStyle = "lime";
      const ty = Math.max(14, ry1 - 6);
      ctx.fillText(label, rx1 + 2, ty);
    }
  }

  async function loadClasses() {
    const res = await fetch(`${apiBase}/classes`);
    const json = await res.json();
    classes = json.classes || [];
    nameToId = new Map(classes.map(c => [c.name, c.id]));
  }

  function sendFilter() {
    if (!ws || ws.readyState !== WebSocket.OPEN) return;

    // 선택이 비어있으면 전체 리셋
    const payload =
      selectedNames.length === 0
        ? { type: "set_filter", class_names: null, class_ids: null }
        : {
            type: "set_filter",
            class_names: selectedNames,
            // (옵션) id도 같이 보내면 서버가 더 빠르게 처리할 수 있음
            class_ids: selectedNames.map(n => nameToId.get(n)).filter(v => v !== undefined)
          };

    ws.send(JSON.stringify(payload));
  }

  function connectWS() {
    ws = new WebSocket(wsUrl);
    status = "connecting";

    ws.onopen = () => {
      status = "connected";
      sendFilter(); // 연결되면 현재 선택 반영
    };

    ws.onmessage = (ev) => {
      const msg = JSON.parse(ev.data);
      lastMsg = msg;

      if (msg.type === "detections") {
        drawBoxes(msg);
      }
    };

    ws.onclose = () => {
      status = "disconnected";
      setTimeout(connectWS, 1000);
    };
  }

  function onSelectChange(e) {
    const opts = Array.from(e.target.selectedOptions);
    selectedNames = opts.map(o => String(o.value));
    sendFilter();
  }

  function resetFilterAll() {
    selectedNames = [];
    sendFilter();
  }

  onMount(async () => {
    ctx = canvas.getContext("2d");
    await loadClasses();
    connectWS();
    window.addEventListener("resize", resizeCanvasToImage);
    return () => window.removeEventListener("resize", resizeCanvasToImage);
  });
</script>

<main style="padding:16px; display:grid; gap:12px;">
  <h1>Real-time YOLO Stream (Filter by Class Name)</h1>
  <div>WS Status: <b>{status}</b></div>

  <section style="display:flex; gap:12px; align-items:flex-start; flex-wrap:wrap;">
    <div style="min-width:280px;">
      <div style="display:flex; justify-content:space-between; align-items:center; gap:8px;">
        <h3 style="margin:0;">클래스 이름 필터</h3>
        <button on:click={resetFilterAll}>전체</button>
      </div>

      <div style="font-size:12px; color:#555; margin:6px 0;">
        여러 개 선택 가능 (Ctrl/Shift)
      </div>

      <select multiple size="14" style="width:100%;" on:change={onSelectChange}>
        {#each classes as c}
          <option value={c.name} selected={selectedNames.includes(c.name)}>
            {c.name} (id: {c.id})
          </option>
        {/each}
      </select>

      <div style="font-size:12px; color:#555; margin-top:6px;">
        선택됨: {selectedNames.length ? selectedNames.join(", ") : "전체"}
      </div>
    </div>

    <div style="position:relative; width:min(960px, 100%); flex:1;">
      <img
        bind:this={liveImg}
        src={`${apiBase}/video`}
        alt="live"
        style="width:100%; display:block; border:1px solid #ccc; border-radius:8px;"
        on:load={resizeCanvasToImage}
      />
      <canvas
        bind:this={canvas}
        style="position:absolute; left:0; top:0; width:100%; height:100%; pointer-events:none;"
      ></canvas>
    </div>
  </section>

  <section>
    <h3>Last message</h3>
    <pre style="white-space:pre-wrap; background:#f7f7f7; padding:12px; border-radius:8px;">
{lastMsg ? JSON.stringify(lastMsg, null, 2) : "waiting..."}
    </pre>
  </section>
</main>
```
