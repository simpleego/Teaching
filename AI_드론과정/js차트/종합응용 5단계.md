# ✅ A. Svelte + Chart.js (5단계)

## 🔹 A-1 정적 데이터 차트

```svelte
<script>
import Chart from "chart.js/auto";

onMount(() => {
  new Chart(canvas, {
    type: "line",
    data: {
      labels: ["A","B","C"],

  });

</script>
```

## 🔹 A-4 주기적 업데이트

```svelte
<script>
import Chart from "chart.js/auto";
import { onMount } from "svelte";
let canvas, chart;

async function fetchData(){
  return await (await fetch("http://localhost:8000/data")).json();
}

onMount(async()=>{
  const data = await fetchData();
  chart = new Chart(canvas,{
    type:"line",
    data:{
      labels:data.map(d=>d.time),
      datasets:[{data:data.map(d=>d.value)}]
    }
  });

  setInterval(async()=>{
    const newData = await fetchData();
    chart.data.labels=newData.map(d=>d.time);
    chart.data.datasets[0].data=newData.map(d=>d.value);
    chart.update();
  },2000);
});
</script>

<canvas bind:this={canvas}></canvas>
```

## 🔹 B-2 WebSocket 수신

```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
<canvas id="c"></canvas>
<script>
let chart=new Chart(c,{
 type:"line",
 data:{labels:[],datasets:[{data:[]}]}
});

const ws=new WebSocket("ws://localhost:8000/ws");

ws.onmessage=(e)=>{
 const d=JSON.parse(e.data);
 chart.data.labels.push(d.time);
 chart.data.datasets[0].data.push(d.value);
 chart.update();
};
</script>
```

---

## 🔹 B-3 FastAPI WebSocket 서버

```python
from fastapi import FastAPI, WebSocket
import random, datetime, asyncio

app=FastAPI()

@app.websocket("/ws")
async def ws(ws:WebSocket):
    await ws.accept()
    while True:
        await ws.send_json({
          "time":datetime.datetime.now().strftime("%H:%M:%S"),
          "value":random.randint(10,100)
        })
        await asyncio.sleep(2)
```
