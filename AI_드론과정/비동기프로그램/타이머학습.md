좋은 주제입니다.
`setTimeout`과 `setInterval`은 **JavaScript 비동기 프로그래밍(Event Loop, Timer Queue)**을 이해하는 핵심 API입니다.
아래는 학습용으로 난이도를 점진적으로 높인 **setTimeout 예제 5개 + setInterval 예제 5개**입니다.
모두 브라우저 콘솔 또는 `<script>`에서 바로 실행 가능합니다.

---

# ✅ setTimeout 예제 5개

---

## 📘 예제 1: 기본 1회 지연 실행

```javascript
console.log("시작");

setTimeout(() => {
  console.log("3초 후 실행");
}, 3000);

console.log("끝");
```

👉 개념: **비동기 실행 순서**

---

## 📘 예제 2: 매개변수 전달

```javascript
function greet(name) {
  console.log("Hello " + name);
}

setTimeout(greet, 2000, "Alice");
```

👉 setTimeout(callback, delay, param1, param2...)

---

## 📘 예제 3: 반복 실행처럼 만들기 (재귀 setTimeout)

```javascript
let count = 0;

function repeatTask() {
  console.log("count:", count);
  count++;

  if (count < 5) {
    setTimeout(repeatTask, 1000);
  }
}

repeatTask();
```

👉 setInterval과의 차이 이해

---

## 📘 예제 4: 취소(clearTimeout)

```javascript
const timerId = setTimeout(() => {
  console.log("이 메시지는 출력되지 않습니다");
}, 5000);

setTimeout(() => {
  clearTimeout(timerId);
  console.log("타이머 취소");
}, 2000);
```

👉 타이머 제어

---

## 📘 예제 5: Promise와 결합

```javascript
function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

async function run() {
  console.log("작업1");
  await delay(2000);
  console.log("작업2 (2초 후)");
}

run();
```

👉 async/await 비동기 패턴

---

# ✅ setInterval 예제 5개

---

## 📗 예제 1: 기본 반복 실행

```javascript
let i = 0;

const id = setInterval(() => {
  console.log("반복:", i++);
}, 1000);
```

---

## 📗 예제 2: 조건에 따라 중단

```javascript
let count = 0;

const timer = setInterval(() => {
  console.log("count:", count);
  count++;

  if (count === 5) {
    clearInterval(timer);
    console.log("종료");
  }
}, 1000);
```

👉 clearInterval

---

## 📗 예제 3: 시계 만들기

```javascript
setInterval(() => {
  const now = new Date();
  console.log(now.toLocaleTimeString());
}, 1000);
```

👉 실제 활용 예

---

## 📗 예제 4: Progress Bar 시뮬레이션

```javascript
let progress = 0;

const bar = setInterval(() => {
  progress += 10;
  console.log("Progress:", progress + "%");

  if (progress >= 100) {
    clearInterval(bar);
    console.log("완료");
  }
}, 500);
```

👉 상태 업데이트

---

## 📗 예제 5: 비동기 작업 감시 (Polling)

```javascript
let serverReady = false;

// 서버 상태 변경 시뮬레이션
setTimeout(() => {
  serverReady = true;
}, 3500);

const check = setInterval(() => {
  console.log("서버 확인 중...");

  if (serverReady) {
    console.log("서버 준비 완료!");
    clearInterval(check);
  }
}, 1000);
```

👉 서버 상태 polling 구조

# 🧠 핵심 개념 정리

| 개념    | setTimeout    | setInterval           |
| ----- | ------------- | --------------------- |
| 실행 방식 | 1회 실행         | 반복 실행                 |
| 취소    | clearTimeout  | clearInterval         |
| 정확도   | 이벤트 루프에 의존    | 누적 오차 발생 가능           |
| 대안    | 재귀 setTimeout | requestAnimationFrame |

---

# ⚠️ 주의사항 (중요)

❌ setInterval은 작업이 오래 걸리면 **중첩 실행 위험**
✅ 안전한 반복은 재귀 setTimeout

```javascript
function safeLoop() {
  setTimeout(() => {
    console.log("작업 수행");
    safeLoop();
  }, 1000);
}
safeLoop();
```
