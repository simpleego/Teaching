아래는 **FastAPI 백엔드 + Svelte 프론트엔드 + Google Charts**를 사용하는 예제 5가지입니다.
각 예제는 **서로 독립적인 구조**이며, 모두 다음 공통 구조를 따릅니다.

구성:

```
project/
 ├─ backend/main.py   (FastAPI)
 └─ frontend/App.svelte (Svelte)
```

Google Charts는 CDN 방식으로 로드합니다:

```html
<script src="https://www.gstatic.com/charts/loader.js"></script>
```

# ✅ 예제 1: 기본 Line Chart (정적 데이터 API)

## 📌 backend/main.py

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/line-data")
def line_data():
    return [
        ["Day", "Sales"],
        ["Mon", 100],
        ["Tue", 150],
        ["Wed", 130],
        ["Thu", 180],
        ["Fri", 200],
    ]
```

## 📌 frontend/App.svelte

```svelte
<script>
  import { onMount } from "svelte";

  let chart;

  onMount(async () => {
    google.charts.load("current", { packages: ["corechart"] });
    google.charts.setOnLoadCallback(drawChart);
  });

  async function drawChart() {
    const res = await fetch("http://localhost:8000/line-data");
    const dataJson = await res.json();

    const data = google.visualization.arrayToDataTable(dataJson);

    const options = {
      title: "Weekly Sales",
    };

    chart = new google.visualization.LineChart(
      document.getElementById("chart")
    );
    chart.draw(data, options);
  }
</script>

<svelte:head>
  <script src="https://www.gstatic.com/charts/loader.js"></script>
</svelte:head>

<div id="chart" style="width:600px;height:400px;"></div>
```

# ✅ 예제 2: Bar Chart (DB처럼 JSON 객체)

## 📌 backend/main.py

```python
@app.get("/bar-data")
def bar_data():
    return {
        "labels": ["A", "B", "C", "D"],
        "values": [10, 30, 20, 40]
    }
```

## 📌 frontend/App.svelte

```svelte
<script>
import { onMount } from "svelte";

onMount(async () => {
  google.charts.load("current", { packages:["corechart"] });
  google.charts.setOnLoadCallback(drawChart);
});

async function drawChart() {
  const res = await fetch("http://localhost:8000/bar-data");
  const json = await res.json();

  let table = [["Item", "Value"]];
  json.labels.forEach((l, i) => {
    table.push([l, json.values[i]]);
  });

  const data = google.visualization.arrayToDataTable(table);

  const chart = new google.visualization.ColumnChart(
    document.getElementById("chart")
  );
  chart.draw(data, { title: "Bar Chart Example" });
}
</script>

<svelte:head>
<script src="https://www.gstatic.com/charts/loader.js"></script>
</svelte:head>

<div id="chart" style="width:600px;height:400px;"></div>
```

# ✅ 예제 4: 실시간 업데이트 Chart (Polling)

## 📌 backend/main.py

```python
import random
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/realtime")
def realtime():
    return [
        ["Time", "Value"],
        ["1", random.randint(0,100)],
        ["2", random.randint(0,100)],
        ["3", random.randint(0,100)],
        ["4", random.randint(0,100)],
    ]
```

## 📌 frontend/App.svelte

```svelte
<script>
import { onMount } from "svelte";

let chart;

onMount(() => {
  google.charts.load("current", { packages:["corechart"] });
  google.charts.setOnLoadCallback(updateChart);
  setInterval(updateChart, 2000);
});

async function updateChart() {
  const res = await fetch("http://localhost:8000/realtime");
  const json = await res.json();

  const data = google.visualization.arrayToDataTable(json);

  if (!chart) {
    chart = new google.visualization.LineChart(
      document.getElementById("chart")
    );
  }

  chart.draw(data, { title: "Realtime Data" });
}
</script>

<svelte:head>
<script src="https://www.gstatic.com/charts/loader.js"></script>
</svelte:head>

<div id="chart" style="width:600px;height:400px;"></div>
```

# ✅ 예제 5: Combo Chart (막대 + 선 혼합)

## 📌 backend/main.py

```python
@app.get("/combo-data")
def combo_data():
    return [
        ["Month", "Sales", "Profit"],
        ["Jan", 1000, 400],
        ["Feb", 1200, 450],
        ["Mar", 900, 300],
        ["Apr", 1500, 600]
    ]
```

## 📌 frontend/App.svelte

```svelte
<script>
import { onMount } from "svelte";

onMount(() => {
  google.charts.load("current", { packages:["corechart"] });
  google.charts.setOnLoadCallback(drawChart);
});

async function drawChart() {
  const res = await fetch("http://localhost:8000/combo-data");
  const json = await res.json();

  const data = google.visualization.arrayToDataTable(json);

  const options = {
    title: "Sales & Profit",
    seriesType: "bars",
    series: {1: {type: "line"}}
  };

  const chart = new google.visualization.ComboChart(
    document.getElementById("chart")
  );
  chart.draw(data, options);
}
</script>

<svelte:head>
<script src="https://www.gstatic.com/charts/loader.js"></script>
</svelte:head>

<div id="chart" style="width:700px;height:400px;"></div>
```
