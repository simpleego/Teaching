# 🟦 **방법 1: IP Webcam 앱 사용 (가장 쉬움, 추천)**  
안드로이드라면 **IP Webcam** 앱이 가장 간단하고 빠른 방법이야.

### 📌 1) 휴대폰에 앱 설치  
Google Play → **IP Webcam** 설치

### 📌 2) 앱 실행 → Start server  
그러면 화면 아래에 이런 주소가 뜬다:

```
http://192.168.0.10:8080/video
```

### 📌 3) PC 파이썬에서 OpenCV로 수신

```python
import cv2
# cv2 파이썬 3.14에서 동작하지 않음

url = "http://192.168.0.10:8080/video"
cap = cv2.VideoCapture(url)

cv2.namedWindow("Phone Camera", cv2.WINDOW_NORMAL)  # ← 핵심
cv2.resizeWindow("Phone Camera", 800, 600)          # 초기 크기 설정

while True:
    ret, frame = cap.read()
    if not ret:
        break

    cv2.imshow("Phone Camera", frame)

    if cv2.waitKey(1) == 27:  # ESC
        break

cap.release()
cv2.destroyAllWindows()
```

✔ 장점  
- 설정 간단  
- 딜레이 적음  
- OpenCV 바로 사용 가능  

✔ 단점  
- 같은 Wi‑Fi에 있어야 함

# 🟩 **방법 2: RTSP 스트리밍 앱 사용 (더 안정적)**  
휴대폰에서 **RTSP 서버**를 켜고 PC에서 수신하는 방식.

### 📌 추천 앱  
- **RTSP Camera Server**  
- **Larix Broadcaster**  
- **DroidCam OBS (RTSP 지원)**

### 📌 파이썬 코드

```python
import cv2

cap = cv2.VideoCapture("rtsp://192.168.0.10:8554/live")

while True:
    ret, frame = cap.read()
    if not ret:
        break

    cv2.imshow("RTSP Stream", frame)

    if cv2.waitKey(1) == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

✔ 장점  
- 딜레이 매우 적음  
- 고화질 가능  
- 안정적  

✔ 단점  
- 앱 설정이 조금 더 필요

# 🟧 **방법 3: DroidCam 사용 (USB 연결도 가능)**  
Wi‑Fi뿐 아니라 **USB 연결도 가능**한 방식.

### 📌 1) 휴대폰에 DroidCam 설치  
### 📌 2) PC에 DroidCam Client 설치  
### 📌 3) PC에서 영상 주소 확인  
보통 이런 주소가 생김:

```
http://127.0.0.1:4747/video
```

### 📌 파이썬 코드

```python
import cv2

cap = cv2.VideoCapture("http://127.0.0.1:4747/video")

while True:
    ret, frame = cap.read()
    if not ret:
        break

    cv2.imshow("DroidCam", frame)

    if cv2.waitKey(1) == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

✔ 장점  
- USB 연결 가능 → 딜레이 거의 없음  
- 설정 쉬움  

✔ 단점  
- PC 클라이언트 설치 필요
