# 1️⃣ RTSP 스트림 수신 (가장 일반적)

```python
import cv2

rtsp_url = "rtsp://192.168.0.10:8554/stream"

cap = cv2.VideoCapture(rtsp_url)

while True:
    ret, frame = cap.read()
    if not ret:
        print("스트림 수신 실패")
        break

    cv2.imshow("RTSP Stream", frame)

    if cv2.waitKey(1) & 0xFF == 27:  # ESC
        break

cap.release()
cv2.destroyAllWindows()
```

# 3️⃣ UDP 스트림 수신 (GStreamer 필요)

### 송신 예 (ffmpeg 또는 드론)

```bash
ffmpeg -re -i video.mp4 -f mpegts udp://127.0.0.1:5000
```

### 수신 코드

```python
import cv2

gst_pipeline = (
    "udpsrc port=5000 ! "
    "application/x-rtp, payload=96 ! "
    "rtpjitterbuffer ! "
    "decodebin ! videoconvert ! appsink"
)

cap = cv2.VideoCapture(gst_pipeline, cv2.CAP_GSTREAMER)

while True:
    ret, frame = cap.read()
    if not ret:
        print("UDP 스트림 실패")
        break

    cv2.imshow("UDP Stream", frame)
    if cv2.waitKey(1) == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

# 4️⃣ TCP 스트림 수신

### ffmpeg 송신

```bash
ffmpeg -re -i video.mp4 -f mpegts tcp://127.0.0.1:6000?listen=1
```

### OpenCV 수신

```python
import cv2

tcp_url = "tcp://127.0.0.1:6000"

cap = cv2.VideoCapture(tcp_url)

while True:
    ret, frame = cap.read()

        break

    cv2.imshow("TCP Stream", frame)

    if cv2.waitKey(1) == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

# 5️⃣ WebRTC 스트림 수신 (aiortc + OpenCV)

OpenCV는 WebRTC 직접 수신 불가 → **aiortc 라이브러리 필요**

### 설치

```bash
pip install aiortc opencv-python
```

### 수신 코드

```python
import cv2
import asyncio
from aiortc import RTCPeerConnection, RTCSessionDescription
from aiortc.contrib.signaling import TcpSocketSignaling

pc = RTCPeerConnection()
signaling = TcpSocketSignaling("127.0.0.1", 9999)

@pc.on("track")
async def on_track(track):
    print("Track received:", track.kind)

    if track.kind == "video":
        while True:
            frame = await track.recv()
            img = frame.to_ndarray(format="bgr24")

            cv2.imshow("WebRTC Stream", img)
            if cv2.waitKey(1) == 27:
                break

async def run():
    await signaling.connect()
    offer = await signaling.receive()
    await pc.setRemoteDescription(offer)

    answer = await pc.createAnswer()
    await pc.setLocalDescription(answer)
    await signaling.send(pc.localDescription)

    await asyncio.sleep(3600)

asyncio.run(run())
```

# 📌 방식별 비교 요약

| 방식     | 장점      | 단점       |
| ------ | ------- | -------- |
| RTSP   | 안정적, 표준 | 지연 발생 가능 |
| HTTP   | 구현 쉬움   | 지연 큼     |
| UDP    | 지연 최소   | 패킷 손실 가능 |
| TCP    | 안정적     | 지연 큼     |
| WebRTC | 초저지연    | 구현 복잡    |
