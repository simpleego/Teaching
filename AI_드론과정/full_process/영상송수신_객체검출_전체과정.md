# 영상송수신_객체검출_전체과정

아래는 기존 **Flask 기반 영상 수신 서버**를
👉 **FastAPI 서버 + Svelte 프론트엔드(Web UI)** 구조로 변경한 전체 예시입니다.

구성:

```
[Client(Camera)] → FastAPI 서버(영상 수신 + 객체검출 YOLO) → Svelte 웹 화면 출력
```

# ✅ 1️⃣ FastAPI 영상 수신 + 객체 검출 서버 (backend/main.py)

```python
# backend/main.py
from fastapi import FastAPI, UploadFile, File
from fastapi.responses import StreamingResponse
import cv2
import numpy as np
from ultralytics import YOLO
import io

app = FastAPI()

model = YOLO("yolov8n.pt")

latest_frame = None  # 가장 최근 프레임 저장

@app.post("/upload")
async def upload_image(file: UploadFile = File(...)):
    global latest_frame

    contents = await file.read()
    npimg = np.frombuffer(contents, np.uint8)
    frame = cv2.imdecode(npimg, cv2.IMREAD_COLOR)

    # 객체 검출
    results = model(frame)
    annotated = results[0].plot()

    latest_frame = annotated
    return {"status": "received"}


def generate_frames():
    global latest_frame
    while True:
        if latest_frame is not None:
            ret, buffer = cv2.imencode('.jpg', latest_frame)
            frame = buffer.tobytes()
            yield (b'--frame\r\n'
                   b'Content-Type: image/jpeg\r\n\r\n' + frame + b'\r\n')


@app.get("/video")
def video_feed():
    return StreamingResponse(generate_frames(),
        media_type="multipart/x-mixed-replace; boundary=frame")


if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

# ✅ 2️⃣ 영상 송신 클라이언트 (sender.py)

```python
# sender.py
import cv2
import requests

SERVER_URL = "http://127.0.0.1:8000/upload"

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    _, img_encoded = cv2.imencode('.jpg', frame)

    files = {"file": img_encoded.tobytes()}
    requests.post(SERVER_URL, files=files)

    cv2.imshow("Sender", frame)
    if cv2.waitKey(1) == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

# ✅ 동작 흐름 요약

1. sender.py → 카메라 영상 프레임을 FastAPI 서버로 전송
2. FastAPI 서버 → YOLO 객체 검출 수행
