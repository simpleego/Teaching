## ✅ 권장 호환 버전 조합

```plaintext
Python: 3.8 - 3.12 (3.11 권장)
```

## 🚀 실제 설치 명령어

### **최신 YOLOv8 환경 구성**
```bash
# 1. Python 3.11 가상환경 (권장)
conda create -n yolo-env python=3.11
conda activate yolo-env

# 2. PyTorch 설치 (CUDA 버전에 맞게)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 3. Ultralytics + OpenCV 설치
pip install ultralytics opencv-python==4.9.0.80
```

### **YOLOv5 환경 구성**
```bash
# Python 3.8 이상
pip install torch>=1.7.0
pip install opencv-python>=4.1.1
pip install ultralytics  # YOLOv8과 통합됨
```

## ⚠️ 주의사항

1. **Python 3.13 사용 시**: 최신 Python은 아직 많은 패키지가 완전히 호환되지 않을 수 있습니다 .

2. **OpenCV headless 버전**: GUI가 없는 서버 환경에서는 `opencv-python-headless` 사용 가능 
   ```bash
   pip install opencv-python-headless
   ```

3. **GPU 사용 시**: PyTorch 버전이 CUDA 버전과 호환되어야 함

4. **설치 충돌 시**: 가상환경 사용을 권장합니다
