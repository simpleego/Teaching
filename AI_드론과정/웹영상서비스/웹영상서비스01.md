## ✅ 전체 구조

```
[영상 전송 서버 (Python/OpenCV)]
        │  (WebSocket, frame bytes)
        ▼
[FastAPI 수신 서버]
        │  (WebSocket)
        ▼
[Svelte 프론트엔드]
   브라우저에서 영상 출력 (canvas/img)
```

영상은 **WebSocket으로 프레임(byte)** 을 보내고,
브라우저에서는 이를 받아 `<canvas>` 에 그립니다.

# 1️⃣ 영상 전송 서버 (Python, Webcam or Video)

```python
# sender.py
import cv2
import websocket
import pickle
import struct

ws = websocket.WebSocket()
ws.connect("ws://localhost:8000/ws")

cap = cv2.VideoCapture(0)  # webcam (또는 video.mp4)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    data = pickle.dumps(frame)
    size = struct.pack("Q", len(data))

    ws.send_binary(size + data)

cap.release()
ws.close()
```

```bash
pip install opencv-python websocket-client
```

# 2️⃣ FastAPI 영상 수신 서버 (WebSocket)

```python
# main.py
from fastapi import FastAPI, WebSocket
import pickle
import struct
import cv2

app = FastAPI()

clients = []

@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    clients.append(websocket)

    data_buffer = b""
    payload_size = struct.calcsize("Q")

    try:
        while True:
            data = await websocket.receive_bytes()
            data_buffer += data

            while len(data_buffer) >= payload_size:
                packed_size = data_buffer[:payload_size]
                data_buffer = data_buffer[payload_size:]
                frame_size = struct.unpack("Q", packed_size)[0]

                while len(data_buffer) < frame_size:
                    data_buffer += await websocket.receive_bytes()

                frame_data = data_buffer[:frame_size]
                data_buffer = data_buffer[frame_size:]

                frame = pickle.loads(frame_data)

                # JPEG 인코딩
                _, buffer = cv2.imencode(".jpg", frame)
                jpg_bytes = buffer.tobytes()

                # 모든 웹 클라이언트로 전송
                for client in clients:
                    await client.send_bytes(jpg_bytes)

    except:
        clients.remove(websocket)
```

실행:

```bash
uvicorn main:app --reload
```

# 3️⃣ Svelte 프론트엔드 (영상 표시)

`App.svelte`

```svelte
<script>
  let socket;
  let imgSrc = "";

  socket = new WebSocket("ws://localhost:8000/ws");
  socket.binaryType = "arraybuffer";

  socket.onmessage = (event) => {
    const blob = new Blob([event.data], { type: "image/jpeg" });
    imgSrc = URL.createObjectURL(blob);
  };
</script>

<h1>영상 스트리밍 화면</h1>

<img {imgSrc} width="640" height="480" />
```

실행:

```bash
npm create vite@latest svelte-video
cd svelte-video
npm install
npm run dev
```
