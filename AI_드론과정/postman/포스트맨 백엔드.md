아주 좋은 주제입니다.
이번에는 **Postman을 “프론트엔드 역할”처럼 사용하여 → 백엔드 서버로 데이터를 보내고 → 백엔드가 그 데이터를 받아 처리하는 방법**을
👉 **완전 처음 쓰는 사용자 기준**으로,
👉 **요청 방식 종류별(GET / POST / PUT / DELETE / Query / Path / Body / Header)** 로 단계별 설명하겠습니다.

---

# ✅ 전체 개념 먼저 이해하기

Postman은 다음 역할을 합니다:

```
Postman (클라이언트, 프론트엔드 역할)
        ↓ 요청(Request)
백엔드 서버(API)
        ↓ 응답(Response)
Postman
```

Postman은:

> 📌 **프론트엔드 없이도 서버 API를 시험하는 도구**입니다.

---

# 🥇 1단계: 가장 기본 — GET 요청 (데이터 요청)

## 🔹 목적: 서버에서 데이터 가져오기

### 1️⃣ Postman 실행

### 2️⃣ New → HTTP Request

### 3️⃣ Method: GET 선택

### 4️⃣ URL 입력

```
http://localhost:8000/users
```

### 5️⃣ Send 클릭

### 📥 서버 응답 예시:

```json
[
  {"id":1,"name":"Kim"},
  {"id":2,"name":"Lee"}
]
```

---

# 🥈 2단계: Query Parameter 방식 (조건 달아 요청)

## 🔹 목적: 조건 검색

### URL 예:

```
http://localhost:8000/users?age=20&city=seoul
```

Postman 설정:

1. Method: GET
2. Params 탭 클릭
3. Key / Value 입력

| Key  | Value |
| ---- | ----- |
| age  | 20    |
| city | seoul |

Postman이 자동으로 URL 생성합니다.

---

# 🥉 3단계: Path Parameter 방식

## 🔹 특정 ID 요청

URL:

```
http://localhost:8000/users/1
```

Postman:

* Method: GET
* URL에 직접 입력
* Send

응답:

```json
{"id":1,"name":"Kim"}
```

---

# 🟢 4단계: POST 요청 (데이터 전송)

## 🔹 목적: 새 데이터 생성

### 1️⃣ Method: POST

### 2️⃣ URL:

```
http://localhost:8000/users
```

### 3️⃣ Body 탭 클릭

### 4️⃣ raw 선택

### 5️⃣ JSON 선택

```json
{
  "name": "Park",
  "age": 25
}
```

### 6️⃣ Send 클릭

응답:

```json
{
  "id":3,
  "name":"Park",
  "age":25
}
```

---

# 🟣 5단계: PUT 요청 (데이터 수정)

## 🔹 목적: 기존 데이터 수정

Method: PUT
URL:

```
http://localhost:8000/users/1
```

Body:

```json
{
  "name": "Kim",
  "age": 30
}
```

---

# 🟠 6단계: DELETE 요청 (데이터 삭제)

Method: DELETE
URL:

```
http://localhost:8000/users/1
```

Send 클릭
응답:

```json
{"message":"deleted"}
```

---

# 🔵 7단계: Header 사용 (인증, 토큰 등)

Headers 탭:

| Key           | Value            |
| ------------- | ---------------- |
| Authorization | Bearer abc123    |
| Content-Type  | application/json |

---

# 🟤 8단계: Form-data 전송 (파일 업로드 포함)

Body → form-data 선택

| Key  | Type | Value     |
| ---- | ---- | --------- |
| name | text | test      |
| file | file | image.jpg |

---

# 🟡 9단계: x-www-form-urlencoded

로그인 등에 자주 사용

```
username=test
password=1234
```

---

# 🔴 10단계: JSON 구조 이해하기 (백엔드 입장)

FastAPI 예시:

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class User(BaseModel):
    name: str
    age: int

@app.post("/users")
def create_user(user: User):
    return {"message": "받은 데이터", "data": user}
```

---

# 🟥 11단계: Postman 요청 종류 정리표

| 방식             | 용도    | 예             |
| -------------- | ----- | ------------- |
| GET            | 조회    | /users        |
| GET + Params   | 검색    | /users?age=20 |
| POST           | 등록    | /users        |
| PUT            | 수정    | /users/1      |
| DELETE         | 삭제    | /users/1      |
| Headers        | 인증    | Authorization |
| Body raw(JSON) | 객체 전송 | {name:...}    |
| form-data      | 파일    | image.jpg     |

---

# ⚠️ 12단계: 초보자가 자주 겪는 오류

### ❌ 415 Unsupported Media Type

→ Body에 JSON인데 Content-Type 안 맞음
✔ raw + JSON 선택

---

### ❌ 422 Validation Error

→ 서버가 원하는 데이터 형식과 다름
✔ key 이름 확인

---

### ❌ 404 Not Found

→ URL 틀림
✔ /users vs /user

---

### ❌ CORS

→ Postman은 CORS 영향 없음 (브라우저만 영향)
