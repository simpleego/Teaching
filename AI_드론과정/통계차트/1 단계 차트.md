# 차트 기능 1단계

아래는 **Chart.js + FastAPI + Svelte** 기반으로
👉 **10단계 난이도별(데이터 구조 & 상황별)** 차트 학습 커리큘럼과
👉 각 단계마다 **백엔드 API + 프론트엔드 코드 예제**를 함께 제공한 실습형 정리입니다.

목표:

* 단순 숫자 배열 → 객체(JSON) → 시계열 → 그룹 통계 → 실시간 → 누적 통계 → 다차원 데이터까지 단계적으로 학습
* 산업용 대시보드/AI 모니터링 UI로 확장 가능

# ✅ STEP 1. 단일 배열 데이터 (기본 Bar Chart)

### 📊 데이터 구조

```json
[10, 20, 30, 40]
```

## FastAPI

```python
@app.get("/step1")
def step1():
    return [10, 20, 30, 40]
```

## Svelte

```svelte
<script>
import Chart from "chart.js/auto";
let chart;

fetch("http://localhost:8000/step1")
.then(r=>r.json())
.then(data=>{
  new Chart(document.getElementById("c1"),{
    type:"bar",
    data:{labels:["A","B","C","D"],datasets:[{data}]}
  });
});
</script>
<canvas id="c1"></canvas>
```

# ✅ STEP 7. 실시간 데이터 (Polling)

## FastAPI

```python
import random
@app.get("/step7")
def step7():
    return random.randint(0,100)
```

## Svelte

```svelte
setInterval(async()=>{
 let v=await fetch("/step7").then(r=>r.json());
 chart.data.datasets[0].data.push(v);
 chart.update();
},1000);
```
