# AI 시대, 비전공자의 파이썬 공부법

핵심은 **코드를 쓰는 능력보다 읽고, 판단하고, 요구하는 능력**을 기르는 것입니다. AI가 코드를 대신 써 주지만, 그 코드가 맞는지 판단하고 무엇을 만들지 정하는 일은 여전히 사람 몫입니다.

## 1. 목표를 바꾼다

| 예전 방식 | 지금 방식 |
|---|---|
| 문법 암기, 빈 화면에서 직접 작성 | AI가 쓴 코드를 읽고 설명할 수 있기 |
| 책 한 권을 처음부터 끝까지 | 만들고 싶은 것부터 정하고 필요한 것만 학습 |
| 에러는 검색으로 해결 | 에러 메시지를 읽고 AI에게 정확히 질문 |
| 많이 아는 것이 실력 | 문제를 잘게 쪼개고 결과를 검증하는 것이 실력 |

## 2. 그래도 직접 익혀야 하는 기초

이 부분은 AI에게 맡기지 말고 손으로 직접 쳐 봐야 합니다. 기초가 없으면 AI의 답이 틀려도 알아챌 수 없습니다.

- **기본 문법**: 변수, 자료형, 조건문, 반복문, 함수
- **자료구조**: 리스트, 딕셔너리 (실무 코드의 대부분이 이 둘)
- **에러 읽기**: Traceback에서 어느 줄이, 왜 틀렸는지 찾기
- **실행 환경**: 파이썬 설치, 패키지 설치(pip), 파일과 폴더 경로, 터미널 기본
- **파일과 데이터 다루기**: CSV·엑셀 읽고 쓰기, 클래스의 기본 개념

## 3. 학습 단계

1. **기초 문법 (2~4주)**: 짧은 예제를 직접 타이핑합니다. 이 단계에서는 AI에게 코드를 받지 말고 "설명해 달라"고만 합니다.
2. **작은 자동화 (1~2개월)**: 내 업무나 생활의 불편을 하나 고릅니다(엑셀 정리, 파일 이름 일괄 변경, 웹 정보 수집 등). AI와 함께 만들되, 받은 코드를 한 줄씩 설명할 수 있을 때까지 질문합니다.
3. **내 분야와 연결 (이후 계속)**: 데이터 분석(pandas), 업무 자동화, 웹 서비스, AI API 활용 중 하나를 골라 프로젝트를 키워 갑니다. 비전공자의 강점은 자기 분야 지식이므로, 그것과 결합할 때 가치가 생깁니다.

## 4. AI를 쓰는 요령

- **이해가 안 되면 넘어가지 않습니다.** "이 줄은 왜 필요해?", "다른 방법은 없어?"라고 묻습니다.
- **먼저 예측하고 실행합니다.** 결과를 미리 짐작해 보고 실제와 비교하면 실력이 빨리 늡니다.
- **가끔은 AI 없이 풀어 봅니다.** 일주일에 한두 번, 쉬운 문제를 혼자 풀어 기초 체력을 확인합니다.
- **요구사항을 구체적으로 씁니다.** 입력, 출력, 예외 상황을 글로 정리하는 연습이 곧 프로그래밍 사고 훈련입니다.
- **결과를 꼭 검증합니다.** AI 코드는 그럴듯하게 틀릴 수 있으니, 작은 데이터로 직접 돌려 확인합니다.

## 5. 흔한 함정

- **복붙만 하고 돌아가면 끝내기**: 몇 달 뒤에도 혼자서는 아무것도 못 고칩니다.
- **강의만 계속 듣기**: 보는 것과 만드는 것은 다릅니다. 강의 1시간이면 실습도 1시간 이상 합니다.
- **처음부터 큰 프로젝트**: 하루 안에 끝낼 수 있는 크기로 쪼개서 시작합니다.
- **문법 완벽주의**: 다 외우려 하지 말고, 필요할 때 찾아 쓰면 됩니다.

어떤 목적(업무 자동화, 데이터 분석, 취업 등)으로 공부하시는지 알려 주시면, 그에 맞춰 주차별 커리큘럼으로 구체화해 드리겠습니다.
