요즘처럼 AI가 코드를 빠르게 만들어주는 환경에서는, 비전공자의 파이썬 학습 목표를 **“코드를 처음부터 외워서 작성하는 능력”에서 “코드를 이해하고, AI에게 요구하고, 검증하고, 수정하는 능력”으로 바꾸는 것**이 좋습니다.

핵심 흐름은 이렇게 잡을 수 있습니다.

```text
과거의 파이썬 학습

문법 암기
  ↓
직접 코딩
  ↓
많은 문제 풀이
  ↓
프로그램 완성


AI 시대의 파이썬 학습

문제 이해
  ↓
처리 절차 설계
  ↓
AI에게 코드 생성 요청
  ↓
생성 코드 읽기
  ↓
실행·테스트
  ↓
오류 원인 판단
  ↓
수정·확장
```

### 1. 그래도 반드시 배워야 하는 파이썬 기초

AI가 코드를 만들어준다고 해도 다음은 반드시 알아야 합니다. 이것을 모르면 AI가 만든 코드가 맞는지 판단하기 어렵습니다.

| 영역 | 반드시 알아야 할 내용 | 학습 수준 |
|---|---|---|
| 변수·자료형 | int, float, str, bool | 확실하게 |
| 컬렉션 | list, dict, tuple, set | 확실하게 |
| 조건문 | if / elif / else | 확실하게 |
| 반복문 | for / while | 확실하게 |
| 함수 | 매개변수, return | 매우 중요 |
| 예외처리 | try / except | 중요 |
| 파일 | txt, CSV, JSON | 중요 |
| 클래스 | class, 객체, 속성, 메서드 | 기본 이해 |
| 모듈 | import, 패키지 | 기본 이해 |
| 가상환경 | venv, pip | 실습 필수 |

반대로 **복잡한 알고리즘을 손으로 많이 구현하거나 문법을 세세하게 암기하는 데 지나치게 많은 시간을 쓸 필요는 없습니다.**

예를 들어 다음 정도는 읽고 설명할 수 있어야 합니다.

```python
scores = [80, 90, 70]

total = sum(scores)
average = total / len(scores)

if average >= 80:
    print("합격")
else:
    print("불합격")
```

중요한 것은 `sum()`을 암기했는지가 아니라,

> scores라는 리스트 → 합계 계산 → 평균 계산 → 평균에 따른 조건 판단

이라는 **데이터와 제어의 흐름을 읽을 수 있는가**입니다.

# 2. AI 시대에는 특히 6가지 능력을 키워야 합니다

제가 비전공자 교육과정이라면 다음 6개를 중심으로 가르치겠습니다.

### ① 코드를 읽는 능력

과거에는

> “이 프로그램을 직접 작성하세요.”

가 중심이었다면, 이제는

> “AI가 작성한 이 코드가 무엇을 하는지 설명하세요.”

가 훨씬 중요합니다.

예를 들어 AI가 다음 코드를 작성했다고 하겠습니다.

```python
def calculate_average(scores):
    if not scores:
        return 0

    return sum(scores) / len(scores)
```

학생이 최소한 다음을 설명해야 합니다.

- `scores`는 무엇인가?
- 왜 `if not scores:`가 필요한가?
- `return 0`은 왜 하는가?
- `sum()`은 무엇인가?
- `len()`은 무엇인가?
- 이 함수를 호출하면 어떤 값이 반환되는가?

**AI 시대의 가장 중요한 프로그래밍 기초 능력 중 하나가 코드 독해력입니다.**

# 3. 직접 코딩보다 먼저 “문제를 구조화하는 능력”을 가르치는 것이 좋습니다

예를 들어 이런 요구사항이 있다고 하겠습니다.

> 학생의 국어, 영어, 수학 점수를 입력받아 총점, 평균, 학점을 계산한다.

곧바로 Python을 작성하지 않고 먼저 구조화합니다.

```text
입력
 ├─ 이름
 ├─ 국어
 ├─ 영어
 └─ 수학

        ↓

처리
 ├─ 총점 계산
 ├─ 평균 계산
 └─ 평균에 따라 학점 계산

        ↓

출력
 ├─ 총점
 ├─ 평균
 └─ 학점
```

그 후 AI에게 요청합니다.

> 위 요구사항을 Python 함수로 작성해줘.  
> 점수는 0~100만 허용하고 잘못된 값은 예외처리해줘.

AI에게 맡길 부분과 사람이 해야 할 부분이 명확해집니다.

**사람**

```text
문제 정의
→ 요구사항
→ 입력/처리/출력 결정
→ 검증 기준 결정
```

**AI**

```text
코드 초안 생성
→ 반복 코드 작성
→ 테스트 코드 생성
→ 리팩터링 제안
```

# 4. AI에게 질문하는 능력이 새로운 프로그래밍 능력입니다

단순하게

> 성적 프로그램 만들어줘

라고 하는 것과,

> Python으로 학생 성적 처리 함수를 작성해줘.  
> 입력은 국어, 영어, 수학 점수이고 각각 0~100이다.  
> 총점과 평균을 계산하고 평균 90 이상 A, 80 이상 B,  
> 70 이상 C, 나머지는 F로 처리한다.  
> 잘못된 점수는 ValueError를 발생시켜라.

라고 요청하는 것은 결과 품질이 크게 다릅니다.

따라서 앞으로의 프로그래밍 수업에서는 **프롬프트 작성법을 별도 과목처럼 가르치기보다 요구사항 분석과 결합**하는 편이 좋습니다.

```text
좋은 요구사항
      ↓
좋은 프롬프트
      ↓
좋은 AI 코드
      ↓
검증
      ↓
좋은 프로그램
```

# 5. AI가 만든 코드를 “검증하는 능력”이 직접 작성 능력보다 중요해지고 있습니다

예를 들어 AI가 성적 프로그램을 만들었다면 학생에게 이렇게 질문하면 됩니다.

> 이 프로그램이 정말 제대로 작동하는가?

테스트 데이터를 생각하게 합니다.

```text
정상 데이터
80, 90, 70

경계값
90, 90, 90
89, 90, 90

최솟값
0, 0, 0

최댓값
100, 100, 100

비정상
-1, 50, 70
101, 80, 90
```

그리고 pytest 같은 도구로 검증합니다.

```python
def test_average():
    result = calculate_scores(80, 90, 70)

    assert result["total"] == 240
    assert result["average"] == 80
    assert result["grade"] == "B"
```

그래서 **AI 시대의 Python 교육에서 테스트를 앞쪽으로 가져오는 것**을 권합니다.

# 6. 오류를 직접 해결하는 대신 “오류를 분석하는 법”을 배워야 합니다

예를 들어 다음 오류가 나왔다고 하겠습니다.

```text
TypeError: unsupported operand type(s)
for +: 'int' and 'str'
```

과거 교육은

> TypeError의 종류를 외워라.

였다면 앞으로는,

```text
1. 오류 메시지를 읽는다.
2. 어느 줄에서 발생했는지 확인한다.
3. 변수의 자료형을 확인한다.
4. AI에게 원인을 설명하게 한다.
5. AI의 설명이 맞는지 코드에서 확인한다.
6. 수정한다.
```

라는 디버깅 절차를 익히는 것이 좋습니다.

즉,

> **에러를 없애는 능력보다 에러를 추적하는 능력**

이 중요합니다.

# 7. “빈 화면에서 코딩하기” 훈련을 지나치게 많이 할 필요는 없습니다

비전공자가 다음 코드를 전부 암기해서 작성하는 데 많은 시간을 쓰는 것은 효율이 떨어집니다.

```python
with open("data.txt", "r", encoding="utf-8") as f:
    data = f.readlines()
```

대신 다음을 이해해야 합니다.

```text
open()        → 파일을 연다
"r"           → 읽기 모드
encoding      → 문자 인코딩
with          → 작업 후 자동으로 파일 닫기
readlines()   → 여러 줄을 읽는다
```

그리고 필요할 때 AI에게 생성시키면 됩니다.

# 8. 그렇다고 AI에게 전부 맡기면 안 됩니다

가장 위험한 학습 패턴은 이것입니다.

```text
문제
 ↓
ChatGPT
 ↓
코드 복사
 ↓
실행
 ↓
성공
 ↓
끝
```

이렇게 학습하면 코드가 조금만 변경되어도 해결할 수 없습니다.

좋은 학습 방법은 다음입니다.

```text
문제
 ↓
내가 먼저 처리 절차 작성
 ↓
AI에게 코드 생성
 ↓
코드 한 줄씩 읽기
 ↓
실행
 ↓
일부 요구사항 변경
 ↓
내가 수정해보기
 ↓
AI에게 검토
 ↓
테스트
```

특히 **“변경 과제”가 매우 효과적**입니다.

AI가 게시판 CRUD를 만들어줬다면 끝내지 않고,

```text
① 검색 기능 추가
② 조회수 추가
③ 작성일 추가
④ 페이지네이션 추가
⑤ 로그인 사용자만 수정
⑥ 관리자만 삭제
```

처럼 요구사항을 계속 변경합니다.

이 과정에서 실제 프로그래밍 실력이 생깁니다.

# 9. 비전공자에게 알고리즘은 어느 수준까지 필요한가?

알고리즘을 공부할 필요가 없다는 뜻은 아닙니다.

다만 코딩 테스트 중심의 알고리즘보다 **프로그램의 사고 구조를 이해하는 정도**를 우선해야 합니다.

꼭 알아야 할 것은 다음 정도입니다.

```text
순차
조건
반복
함수 분리

리스트 순회
검색
필터링
정렬

데이터 추가
수정
삭제
조회
```

그리고 자료구조도,

```text
list
dict
set
tuple
```

을 **언제 사용하는지를 판단하는 능력**이 우선입니다.

연결 리스트, AVL Tree, Red-Black Tree 등을 직접 구현하는 것은 일반적인 AI 풀스택 개발 입문 단계에서는 우선순위가 훨씬 낮습니다.

# 11. 수업 방식도 바꾸는 것이 좋습니다

예를 들어 기존 수업이

```text
강사 설명 30분
→ 예제 따라하기 30분
→ 비슷한 문제 직접 코딩
```

이었다면 AI 시대에는 이렇게 바꿀 수 있습니다.

```text
① 문제 제시
      ↓
② 학생이 처리 절차 작성
      ↓
③ AI에게 구현 요청
      ↓
④ AI 코드 분석
      ↓
⑤ 실행
      ↓
⑥ 오류 찾기
      ↓
⑦ 요구사항 변경
      ↓
⑧ AI와 수정
      ↓
⑨ 테스트
      ↓
⑩ 코드 설명
```

평가 방식도 바꾸는 것이 좋습니다.

예를 들어,

> Python으로 회원관리 프로그램을 작성하세요.

보다

> 다음 AI 생성 회원관리 코드를 분석하여 문제점 3가지를 찾고 수정하세요.

또는

> 다음 요구사항을 AI에게 구현시키기 위한 프롬프트를 작성하고, 생성된 코드를 검증하세요.

또는

> AI가 작성한 코드에 검색 기능을 추가하고 변경 이유를 설명하세요.

같은 문제가 실무 능력을 훨씬 잘 평가합니다.

# 12. 최종적으로 갖춰야 하는 능력

앞으로의 비전공 Python 학습 목표는 저는 다음과 같이 보는 것이 적절하다고 생각합니다.

```text
              AI 시대 개발자

        ┌───────────────┐
        │ 문제를 이해한다 │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │ 요구사항을 만든다 │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │ AI에게 구현시킨다 │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │ 코드를 읽는다    │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │ 실행·테스트한다   │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │ 오류를 판단한다   │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │ 수정·확장한다    │
        └───────────────┘
```

그래서 한 문장으로 정리하면,

> **AI 시대의 Python 교육은 “코드를 잘 작성하는 사람”을 만드는 교육에서, “프로그램을 이해하고 설계하며 AI가 만든 코드를 검증·수정할 수 있는 사람”을 만드는 교육으로 바뀌어야 합니다.**

특히 현재 진행하시는 **AX 풀스택 과정**처럼 최종 목표가 FastAPI·DB·프론트엔드·AI를 연결해 서비스를 만드는 것이라면, 파이썬 문법에 지나치게 많은 시간을 투자하기보다는 **Python 기본기 → 코드 독해 → 요구사항 → AI 코딩 → 디버깅 → 테스트 → Git → 프로젝트 수정·확장** 순서로 연결하는 것이 효과적입니다.
