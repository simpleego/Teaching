# AI활용한 풀스택 웹 개발자 과정

>  **비전공자가 5개월(하루 8시간) 동안 AI 시대에 맞는 풀스택 웹 개발자로 성장하는 교육과정**을 “실제로 운영 가능한 수준”으로 설계해줄게.  
> AI 시대 개발자의 핵심 역량을 기반으로 구성했고, **AI 활용 능력 + CS 기초 + 웹 풀스택 + 협업 + 프로젝트**를 모두 포함한 실전형 커리큘럼이야.

아래 커리큘럼은 **총 5개월(약 800시간)** 기준으로 설계했어.  
(국내 부트캠프 기준과 AI 교육 트렌드 참고   [aileap.co.kr](https://aileap.co.kr/)  [koreaitacademy.ai.kr](https://koreaitacademy.ai.kr/web-app-developer-course/))

# 🎯 **최종 목표**
- **AI 시대에 적합한 풀스택 웹 개발자 양성**
- 비전공자도 따라올 수 있는 단계적 구성
- 실무 중심 + 프로젝트 중심
- AI를 활용한 개발 생산성 극대화
- GitHub 기반 협업 능력 확보
- 포트폴리오 2~3개 완성

# 🧠 **AI 시대 개발자의 핵심 역량**
AI 시대 개발자가 갖춰야 할 역량을 기반으로 커리큘럼을 설계했어.

### ✔ 기술 역량
- 프로그래밍 기초(Python + JavaScript)
- 웹 프론트엔드(HTML/CSS/JS/React)
- 웹 백엔드(Node.js + Express)
- 데이터베이스(MySQL/PostgreSQL)
- API 설계 및 통신
- 배포(Docker, 클라우드)

### ✔ AI 활용 역량
- ChatGPT·Copilot 기반 개발 생산성 향상
- 코드 리뷰 자동화
- AI 기반 디버깅
- AI 기반 문서화
- AI 기반 설계 보조
- 간단한 AI 기능을 웹 서비스에 통합

### ✔ 협업 역량
- Git/GitHub 브랜치 전략
- Pull Request 기반 협업
- 이슈 관리
- 코드 리뷰

### ✔ CS 기초 역량
- 자료구조·알고리즘 기초
- 네트워크 기초(HTTP, REST)
- 운영체제 기초(프로세스, 메모리)
- 데이터베이스 기본 개념

### 🔹 학습 목표
- 프로그래밍 기본기 확보
- 웹 개발의 전체 구조 이해
- CS 기초 개념 습득
- AI 도구를 활용한 학습 습관 형성

### 🔹 학습 내용
- Python 기초  
- JavaScript 기초  
- Git/GitHub 기본  
- 자료구조·알고리즘 기초  
- 네트워크 기초(HTTP/REST)  
- 운영체제 기초(프로세스·스레드)

- React Router  

### 🔹 실습
- 개인 포트폴리오 웹사이트 제작
