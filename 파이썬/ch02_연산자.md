## 2.1 산술 연산자

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `+` | 덧셈 | `7 + 3` | 10 |
| `-` | 뺄셈 | `7 - 3` | 4 |
| `*` | 곱셈 | `7 * 3` | 21 |
| `/` | 나눗셈(항상 float) | `7 / 2` | 3.5 |
| `//` | 몫(정수 나눗셈) | `7 // 2` | 3 |
| `%` | 나머지 | `7 % 2` | 1 |
| `**` | 거듭제곱 | `2 ** 10` | 1024 |

```python
a, b = 17, 5

print(a + b)      # 22
print(a - b)      # 12
print(a * b)      # 85
print(a / b)      # 3.4   ← 정수끼리 나눠도 결과는 실수
print(a // b)     # 3     ← 몫
print(a % b)      # 2     ← 나머지
print(a ** 2)     # 289

# divmod: 몫과 나머지를 한 번에
q, r = divmod(a, b)
print(q, r)       # 3 2

# ⚠️ 음수 몫은 '내림(floor)' 방향
print(-7 // 2)    # -4  (−3.5를 내림)
print(-7 % 2)     # 1

# 활용: 짝수/홀수 판별, 자릿수 분리
print(10 % 2 == 0)        # True → 짝수
num = 1234
print(num // 100 % 10)    # 2 (백의 자리)

# 문자열·리스트에도 + 와 * 사용 가능
print("가" + "나")         # 가나
print("-" * 20)           # 구분선
print([0] * 5)            # [0, 0, 0, 0, 0]
print([1, 2] + [3])       # [1, 2, 3]
```

## 2.2 대입(복합 대입) 연산자

```python
x = 10
x += 5     # x = x + 5   → 15
x -= 3     # x = x - 3   → 12
x *= 2     # x = x * 2   → 24
x /= 4     # x = x / 4   → 6.0
x //= 4    # x = x // 4  → 1.0
x **= 3    # x = x ** 3  → 1.0
x %= 1     # x = x % 1   → 0.0
print(x)

# 문자열/리스트에도 적용
msg = "안녕"
msg += "하세요"
print(msg)                # 안녕하세요

# 바다코끼리 연산자(:=, walrus) – 대입과 동시에 값 사용 (3.8+)
data = [1, 2, 3, 4, 5]
if (n := len(data)) > 3:
    print(f"데이터가 {n}개로 많습니다")
```

## 2.3 비교 연산자

```python
a, b = 10, 20
print(a == b)     # False 같다
print(a != b)     # True  다르다
print(a > b)      # False
print(a < b)      # True
print(a >= 10)    # True
print(a <= 9)     # False

# 연쇄 비교 (파이썬만의 장점)
score = 85
print(80 <= score < 90)   # True → 'score가 80 이상 90 미만'

# 문자열 비교: 사전순(유니코드 코드 순서)
print("apple" < "banana")  # True
print("가" < "나")          # True

# 리스트/튜플 비교: 앞 요소부터 차례로
print([1, 2, 3] < [1, 3])  # True (두 번째 요소 2 < 3)
```

## 2.4 논리 연산자: and, or, not

```python
kor, eng = 70, 50

# and: 둘 다 참이어야 참
print(kor >= 60 and eng >= 60)   # False

# or: 하나라도 참이면 참
print(kor >= 60 or eng >= 60)    # True

# not: 반전
print(not kor >= 60)             # False

# ▶ 단락 평가(short-circuit)
# and: 앞이 거짓이면 뒤는 평가하지 않음
# or : 앞이 참이면 뒤는 평가하지 않음
divisor = 0
print(divisor != 0 and 10 / divisor > 1)  # False (나눗셈 실행 안 됨 → 에러 없음)

# ▶ and/or는 bool이 아니라 '마지막으로 평가한 값'을 반환
print(0 or "기본값")         # 기본값
print("입력값" or "기본값")    # 입력값
print(3 and 5)               # 5
print(0 and 5)               # 0

# 활용: 입력이 비어 있으면 기본값 사용
user_input = ""
name = user_input or "익명"
print(name)                  # 익명
```

## 2.5 비트 연산자

```python
a, b = 0b1100, 0b1010     # 12, 10

print(bin(a & b))   # 0b1000  AND
print(bin(a | b))   # 0b1110  OR
print(bin(a ^ b))   # 0b110   XOR
print(~a)           # -13     NOT (−(a+1))
print(a << 2)       # 48      왼쪽 시프트 (×4)
print(a >> 2)       # 3       오른쪽 시프트 (÷4)

# 활용: 권한 플래그
READ, WRITE, EXEC = 0b100, 0b010, 0b001
perm = READ | WRITE              # 읽기+쓰기 권한
print(bool(perm & WRITE))        # True  쓰기 가능?
print(bool(perm & EXEC))         # False 실행 가능?
```

## 2.6 멤버십 연산자: in, not in

```python
subjects = ["국어", "영어", "수학"]
print("수학" in subjects)        # True
print("과학" not in subjects)    # True

print("py" in "python")          # True (부분 문자열)

stock = {"콜라": 3, "사이다": 0}
print("콜라" in stock)            # True (딕셔너리는 '키'를 검사)
print(3 in stock)                # False
print(3 in stock.values())       # True
```

## 2.7 식별 연산자: is, is not

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)      # True  → 값이 같은가?
print(a is b)      # False → 같은 객체인가?
print(a is c)      # True

# None, True, False 비교에는 is 사용이 관례
result = None
print(result is None)        # 권장
print(result is not None)
```

## 2.8 연산자 우선순위 (높음 → 낮음)

| 순위 | 연산자 |
|---|---|
| 1 | `()` 괄호 |
| 2 | `**` |
| 3 | `+x`, `-x`, `~x` (단항) |
| 4 | `*`, `/`, `//`, `%` |
| 5 | `+`, `-` |
| 6 | `<<`, `>>` |
| 7 | `&` |
| 8 | `^` |
| 9 | `\|` |
| 10 | 비교, `in`, `is` |
| 11 | `not` |
| 12 | `and` |
| 13 | `or` |
| 14 | `:=` |

```python
print(2 + 3 * 4)        # 14 (곱셈 먼저)
print((2 + 3) * 4)      # 20
print(-2 ** 2)          # -4  (** 가 단항 - 보다 먼저!)
print((-2) ** 2)        # 4
print(2 ** 3 ** 2)      # 512 (** 는 오른쪽부터: 3**2=9 → 2**9)
print(not True or True) # True ((not True) or True)

# 💡 헷갈리면 괄호를 쓰는 것이 가장 좋은 습관입니다.
```

## 2.9 시퀀스 연산과 조건(삼항) 표현식

```python
# 조건 표현식: 값1 if 조건 else 값2
score = 75
result = "합격" if score >= 60 else "불합격"
print(result)

# 언패킹 연산자 * / ** (자세한 활용은 4장)
nums = [1, 2, 3]
print(*nums)                    # 1 2 3
merged = [*nums, 4, 5]
print(merged)
d1 = {"a": 1}
d2 = {**d1, "b": 2}
print(d2)                       # {'a': 1, 'b': 2}
```

## 🧪 예제 프로그램 ①: 사칙연산 계산기 v1

```python
# ===== 계산기 v1: 연산자만 사용 (제어문은 3장에서) =====
a = 17
b = 4

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")
print(f"{a} / {b} = {a / b:.2f}")
print(f"{a} // {b} = {a // b}")
print(f"{a} % {b} = {a % b}")
print(f"{a} ** {b} = {a ** b}")

# 0으로 나누는지 미리 확인 (단락 평가 활용)
b2 = 0
safe = b2 != 0 and a / b2
print("나눗셈 결과:", safe if safe is not False else "0으로 나눌 수 없음")
```

## 🧪 예제 프로그램 ②: 성적표 v2 – 총점·평균·합격 판정

```python
# ===== 성적표 v2 =====
name = "홍길동"
kor, eng, math = 90, 55, 77

total = kor + eng + math
avg = total / 3

# 모든 과목 40점 이상 AND 평균 60 이상이면 합격
is_pass = (kor >= 40 and eng >= 40 and math >= 40) and avg >= 60

# 과락 과목 존재 여부
has_fail = kor < 40 or eng < 40 or math < 40

print(f"이름: {name}")
print(f"총점: {total}, 평균: {avg:.1f}")
print(f"과락 있음: {has_fail}")
print(f"최종: {'합격' if is_pass else '불합격'}")
```

## 🧪 예제 프로그램 ③: 자판기 거스름돈 계산

```python
# ===== 자판기 v1: 거스름돈을 동전 단위로 분해 =====
price = 1_350
paid = 5_000
change = paid - price            # 3650

c1000, rest = divmod(change, 1000)
c500, rest = divmod(rest, 500)
c100, rest = divmod(rest, 100)
c50, rest = divmod(rest, 50)

print(f"거스름돈 {change:,}원")
print(f"1000원 {c1000}장, 500원 {c500}개, 100원 {c100}개, 50원 {c50}개")
```

**실행 결과**
```
거스름돈 3,650원
1000원 3장, 500원 1개, 100원 1개, 50원 1개
```
