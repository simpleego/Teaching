## 1.1 변수(Variable)

### 개념
파이썬에서 변수는 **값(객체)을 가리키는 이름표**입니다. 상자에 값을 "담는다"기보다, 메모리 어딘가에 만들어진 객체에 이름을 "붙인다"고 이해하는 것이 정확합니다.

```python
# 변수 선언과 동시에 값 대입 (자료형 선언이 필요 없음 → 동적 타이핑)
name = "홍길동"      # 문자열 객체에 name이라는 이름표를 붙임
score = 95           # 정수 객체에 score라는 이름표를 붙임

print(name, score)   # 홍길동 95

# 같은 변수에 다른 형의 값을 다시 대입할 수 있음
score = "A+"         # 이제 score는 문자열을 가리킴
print(score)         # A+

# id()로 객체의 고유 번호(메모리 주소 개념)를 확인
a = 10
b = a                # b도 같은 객체 10을 가리킴
print(id(a) == id(b))  # True
```

### 다중 대입과 값 교환
```python
# 여러 변수에 한 번에 대입
x, y, z = 1, 2, 3
print(x, y, z)       # 1 2 3

# 같은 값을 여러 변수에
a = b = c = 0
print(a, b, c)       # 0 0 0

# 두 변수의 값 교환 (임시 변수 불필요)
x, y = y, x
print(x, y)          # 2 1

# 언패킹 시 나머지를 리스트로 받기 (* 사용)
first, *rest = [90, 85, 77, 60]
print(first)         # 90
print(rest)          # [85, 77, 60]
```

### 변수 이름 규칙
```python
# ✅ 가능: 영문자, 숫자, 밑줄(_), 한글(권장하지 않음). 숫자로 시작 불가
student_name = "김철수"   # 스네이크 케이스(파이썬 권장 스타일)
_temp = 1                 # 밑줄로 시작 → 관례적으로 '내부용'
MAX_SCORE = 100           # 모두 대문자 → 관례적으로 '상수'

# ❌ 불가능
# 1st_score = 90          # 숫자로 시작 → SyntaxError
# class = "A"             # 예약어(키워드) 사용 불가

import keyword
print(keyword.kwlist)     # 사용할 수 없는 예약어 목록 출력
```

## 1.2 숫자형: int, float, complex

```python
# 정수(int): 크기 제한이 없음
count = 42
big = 2 ** 100            # 아주 큰 수도 그대로 표현
print(big)                # 1267650600228229401496703205376

# 진법 표기
print(0b1010)             # 2진수 → 10
print(0o17)               # 8진수 → 15
print(0xFF)               # 16진수 → 255

# 자릿수 구분용 밑줄 (가독성)
price = 1_000_000
print(price)              # 1000000

# 실수(float): 소수점이 있는 수
avg = 87.5
sci = 1.5e3               # 지수 표기 → 1500.0
print(avg, sci)

# ⚠️ 실수 오차: 2진수로 소수를 정확히 표현할 수 없기 때문
print(0.1 + 0.2)          # 0.30000000000000004
print(round(0.1 + 0.2, 2))  # 0.3 → 반올림으로 처리

# 복소수(complex)
c = 3 + 4j
print(c.real, c.imag)     # 3.0 4.0
print(abs(c))             # 5.0 (크기)
```

## 1.3 불리언(bool)과 None

```python
# bool: True / False (첫 글자 대문자)
is_pass = True
is_absent = False
print(type(is_pass))      # <class 'bool'>

# bool은 int의 하위 타입 → True는 1, False는 0
print(True + True)        # 2

# 참/거짓 판정(Truthy / Falsy)
# 거짓으로 취급되는 값: 0, 0.0, "", [], (), {}, set(), None, False
print(bool(0), bool(""), bool([]), bool(None))   # False False False False
print(bool(1), bool("a"), bool([0]))             # True True True

# None: '값이 없음'을 나타내는 특별한 객체
grade = None              # 아직 학점이 정해지지 않음
print(grade is None)      # True  (None 비교는 is를 사용)
```

## 1.4 문자열(str)

### 생성과 이스케이프 문자
```python
s1 = '작은따옴표'
s2 = "큰따옴표"
s3 = """여러 줄
문자열도
가능"""
print(s3)

# 이스케이프 문자
print("줄\n바꿈")          # \n: 줄바꿈
print("탭\t문자")          # \t: 탭
print("따옴표 \"출력\"")    # \": 큰따옴표
print("역슬래시 \\")        # \\: 역슬래시

# raw 문자열: 이스케이프 무시 (파일 경로, 정규식에 유용)
print(r"C:\new\test")      # C:\new\test
```

### 인덱싱과 슬라이싱
```python
word = "PYTHON"
#       P  Y  T  H  O  N
# 인덱스 0  1  2  3  4  5
# 음수  -6 -5 -4 -3 -2 -1

print(word[0])       # P
print(word[-1])      # N (뒤에서 첫 번째)
print(word[0:2])     # PY  (0 이상 2 미만)
print(word[2:])      # THON
print(word[:3])      # PYT
print(word[::2])     # PTO (2칸씩 건너뛰기)
print(word[::-1])    # NOHTYP (뒤집기)

# 문자열은 불변(immutable) → 일부만 바꿀 수 없음
# word[0] = "J"      # TypeError!
word = "J" + word[1:]  # 새 문자열을 만들어야 함
print(word)            # JYTHON
```

### 주요 문자열 메서드
```python
text = "  Hello, Python World  "

print(text.strip())          # 양쪽 공백 제거 → "Hello, Python World"
print(text.lstrip())         # 왼쪽 공백 제거
print(text.rstrip())         # 오른쪽 공백 제거
print(text.upper())          # 대문자로
print(text.lower())          # 소문자로
print(text.replace("Python", "파이썬"))  # 치환
print(text.count("o"))       # 'o'의 개수 → 3
print(text.find("Python"))   # 처음 위치 인덱스 → 9 (없으면 -1)
print(text.strip().startswith("Hello"))  # True
print(text.strip().endswith("World"))    # True

# 분리와 결합
csv = "국어,영어,수학"
subjects = csv.split(",")    # ['국어', '영어', '수학']
print(subjects)
print(" | ".join(subjects))  # 국어 | 영어 | 수학

# 판별 메서드
print("123".isdigit())       # True  (숫자로만 구성?)
print("abc".isalpha())       # True  (문자로만 구성?)
print("abc123".isalnum())    # True  (문자+숫자?)

# 정렬
print("성적".center(10, "*"))  # ****성적****
print("5".zfill(3))            # 005
```

### 문자열 포매팅 (3가지 방식)
```python
name, score = "홍길동", 92.456

# ① % 포매팅 (구식)
print("%s님의 점수는 %.1f점" % (name, score))

# ② str.format()
print("{}님의 점수는 {:.1f}점".format(name, score))
print("{0}님, {0}님의 점수는 {1}점".format(name, 90))  # 인덱스 재사용

# ③ f-string (파이썬 3.6+, 가장 권장)
print(f"{name}님의 점수는 {score:.1f}점")

# f-string 서식 지정 예시
n = 1234567
print(f"{n:,}")          # 1,234,567 (천 단위 콤마)
print(f"{n:>12}")        # 오른쪽 정렬 12칸
print(f"{name:<6}|")     # 왼쪽 정렬
print(f"{name:^10}|")    # 가운데 정렬
print(f"{0.875:.1%}")    # 87.5%
print(f"{255:b} {255:x}")  # 11111111 ff
print(f"{score = }")     # 디버깅용: score = 92.456 (3.8+)
```

## 1.5 리스트(list) – 순서 O, 변경 O

```python
scores = [90, 85, 77]

# 추가
scores.append(60)            # 끝에 추가 → [90, 85, 77, 60]
scores.insert(0, 100)        # 0번 위치에 삽입 → [100, 90, 85, 77, 60]
scores.extend([70, 80])      # 여러 개 이어붙이기

# 삭제
scores.remove(77)            # 값으로 삭제 (첫 번째 하나)
last = scores.pop()          # 마지막 요소 꺼내며 삭제
first = scores.pop(0)        # 0번 요소 꺼내며 삭제
del scores[0]                # 인덱스로 삭제
print(scores, last, first)

# 검색/정보
nums = [3, 1, 4, 1, 5, 9, 2]
print(len(nums))             # 7
print(nums.index(4))         # 2 (값 4의 위치)
print(nums.count(1))         # 2
print(5 in nums)             # True

# 정렬
nums.sort()                  # 원본을 오름차순 정렬
print(nums)
nums.sort(reverse=True)      # 내림차순
print(nums)
print(sorted([3, 1, 2]))     # 원본은 두고 정렬된 새 리스트 반환
nums.reverse()               # 순서 뒤집기

# 슬라이싱으로 수정
nums[0:2] = [100, 200]
print(nums)

# 중첩 리스트 (2차원)
matrix = [[1, 2, 3], [4, 5, 6]]
print(matrix[1][2])          # 6

# ⚠️ 복사 주의
a = [1, 2, 3]
b = a                        # 같은 리스트를 가리킴(얕은 참조)
b.append(4)
print(a)                     # [1, 2, 3, 4] ← a도 바뀜!
c = a.copy()                 # 또는 a[:], list(a) → 새 리스트
c.append(5)
print(a, c)                  # [1, 2, 3, 4] [1, 2, 3, 4, 5]
```

## 1.7 딕셔너리(dict) – 키:값 쌍

```python
student = {"name": "홍길동", "kor": 90, "eng": 85}

# 조회
print(student["name"])               # 홍길동
print(student.get("math"))           # None (키가 없어도 에러 없음)
print(student.get("math", 0))        # 0 (기본값 지정)

# 추가/수정
student["math"] = 77                 # 없으면 추가
student["kor"] = 95                  # 있으면 수정
student.update({"eng": 88, "sci": 70})

# 삭제
del student["sci"]
eng = student.pop("eng")             # 꺼내며 삭제
print(student, eng)

# 순회용 뷰
print(student.keys())
print(student.values())
print(student.items())               # (키, 값) 튜플들

for key, value in student.items():
    print(f"{key} → {value}")

# 키 존재 여부
print("name" in student)             # True

# setdefault: 키가 없을 때만 기본값 설정
student.setdefault("grade", "미정")
print(student["grade"])

# dict 생성 다른 방법
d1 = dict(a=1, b=2)
d2 = dict(zip(["x", "y"], [10, 20]))
d3 = dict.fromkeys(["국어", "영어"], 0)
print(d1, d2, d3)

# 병합 연산자 (3.9+)
print(d1 | {"c": 3})
```

## 1.8 집합(set) – 순서 X, 중복 X

```python
s = {1, 2, 2, 3, 3, 3}
print(s)                     # {1, 2, 3} 중복 자동 제거
empty = set()                # ⚠️ {}는 빈 딕셔너리!

s.add(4)                     # 추가
s.update([5, 6])             # 여러 개 추가
s.discard(10)                # 없어도 에러 없음
s.remove(1)                  # 없으면 KeyError
print(s)

# 집합 연산
python_cls = {"철수", "영희", "민수"}
java_cls = {"영희", "민수", "지훈"}
print(python_cls & java_cls)  # 교집합 {'영희', '민수'}
print(python_cls | java_cls)  # 합집합
print(python_cls - java_cls)  # 차집합 {'철수'}
print(python_cls ^ java_cls)  # 대칭차집합 {'철수', '지훈'}

# 활용: 리스트 중복 제거
names = ["a", "b", "a", "c"]
print(list(set(names)))

# frozenset: 불변 집합
fs = frozenset([1, 2])
```

## 1.10 가변(mutable) vs 불변(immutable)

| 구분 | 데이터형 | 특징 |
|---|---|---|
| 불변 | int, float, bool, str, tuple, frozenset | 값을 바꾸면 **새 객체**가 생성됨 |
| 가변 | list, dict, set | 같은 객체 내부를 직접 수정 가능 |

```python
# 불변: 값을 바꾸면 id가 달라짐
x = 10
print(id(x))
x += 1
print(id(x))          # 다른 id → 새 객체

# 가변: 내용을 바꿔도 id 동일
lst = [1, 2]
print(id(lst))
lst.append(3)
print(id(lst))        # 같은 id

# 얕은 복사 vs 깊은 복사
import copy
origin = [[1, 2], [3, 4]]
shallow = copy.copy(origin)
deep = copy.deepcopy(origin)
origin[0].append(99)
print(shallow)        # [[1, 2, 99], [3, 4]] ← 내부 리스트 공유
print(deep)           # [[1, 2], [3, 4]]     ← 완전히 독립
```

## 🧪 예제 프로그램: 성적표 데이터 설계 (v1)

> 이 장에서 배운 데이터형만으로 성적표를 표현합니다. 이후 장에서 연산자 → 제어문 → 함수 → 클래스 순으로 점점 발전시킵니다.

```python
# ===== 성적표 v1: 데이터형만 사용 =====

# 과목 목록: 순서가 바뀌면 안 되므로 튜플
SUBJECTS = ("국어", "영어", "수학")

# 학생 1명 = 딕셔너리, 점수 = 리스트
student1 = {"name": "홍길동", "scores": [90, 85, 77]}
student2 = {"name": "김영희", "scores": [95, 92, 88]}

# 학급 = 학생 딕셔너리들의 리스트
class_list = [student1, student2]

# 과목별 점수 딕셔너리 만들기 (zip은 7장에서 자세히)
s1_detail = dict(zip(SUBJECTS, student1["scores"]))
print(s1_detail)    # {'국어': 90, '영어': 85, '수학': 77}

# 총점과 평균 (sum, len 내장함수 사용)
total = sum(student1["scores"])
average = total / len(student1["scores"])

# 출력 (f-string 서식)
print("=" * 30)
print(f"{'이름':^6}|{'총점':^6}|{'평균':^8}")
print("-" * 30)
print(f"{student1['name']:^6}|{total:^8}|{average:^8.2f}")
print("=" * 30)

# 수강 과목에서 중복 없는 전체 과목 (set 활용)
extra = {"과학", "수학"}
all_subjects = set(SUBJECTS) | extra
print(sorted(all_subjects))
```

**실행 결과**
```
{'국어': 90, '영어': 85, '수학': 77}
==============================
  이름  |  총점  |   평균   
------------------------------
 홍길동 |  252   |  84.00  
==============================
['과학', '국어', '수학', '영어']
```
