# 밑바닥부터 시작하는 딥러닝 시리즈

**1권** 밑바닥부터 시작하는 딥러닝 1 파이썬으로 익히는 딥러닝 이론과 구현

- 1장 헬로 파이썬
  파이썬 설치, 인터프리터, 변수·리스트·딕셔너리·bool·제어문·함수, 클래스, NumPy(배열·산술·브로드캐스트), matplotlib

- 2장 퍼셉트론
  퍼셉트론 원리, AND/NAND/OR 게이트, 가중치와 편향, 퍼셉트론의 한계(XOR), 다층 퍼셉트론, NAND에서 컴퓨터까지

- 3장 신경망
  활성화 함수(시그모이드·계단·ReLU), 다차원 배열, 3층 신경망 구현, 출력층 설계(항등·소프트맥스), MNIST 추론

- 4장 신경망 학습
  데이터 주도 학습, 손실 함수(MSE·교차 엔트로피), 미니배치, 수치 미분, 기울기, 학습 알고리즘 구현

- 5장 오차역전파법
  계산 그래프, 연쇄법칙, 역전파, ReLU·Sigmoid·Affine·Softmax-with-Loss 계층, 오차역전파법 구현

- 6장 학습 관련 기술들
  SGD·Momentum·AdaGrad·Adam, 가중치 초깃값(Xavier·He), 배치 정규화, 과적합·드롭아웃, 하이퍼파라미터 최적화

- 7장 합성곱 신경망 (CNN)
  합성곱 계층, 풀링 계층, 3D 데이터 처리, 대표적 CNN(LeNet·AlexNet), im2col 구현

- 8장 딥러닝
  더 깊은 네트워크, 역사(VGG·GoogLeNet·ResNet·DenseNet), 고속화·경량화, 딥러닝 활용(물체 감지·분할·생성), 미래

**2권** 밑바닥부터 시작하는 딥러닝 2 파이썬으로 직접 구현하며 배우는 순환 신경망과 자연어 처리

- 1장 신경망 복습
  벡터·행렬, 신경망 추론, 손실함수·역전파, 신경망 학습 구현, 16비트 반정밀도·cupy

- 2장 자연어와 단어의 분산 표현
  시소러스 기법, 통계 기반 기법(분포가설·동시발생행렬·유사도·SVD), 차원 감소

- 3장 word2vec
  추론 기반 기법, CBOW 모델 구현, 맥락과 타깃, skip-gram, 통계 기반 vs 추론 기반 비교

- 4장 word2vec 속도 개선
  Embedding 계층, 네거티브 샘플링, 개선판 word2vec 학습, PTB 데이터셋

- 5장 순환 신경망 (RNN)
  확률과 언어 모델, RNN 구조·역전파(BPTT), Truncated BPTT, RNNLM 구현

- 6장 게이트가 추가된 RNN
  LSTM 구조(망각·입력·출력 게이트), GRU, 개선된 RNNLM

- 7장 RNN을 사용한 문장 생성
  RNNLM을 이용한 문장 생성, seq2seq(Encoder-Decoder), 덧셈 문제 학습

- 8장 어텐션
  어텐션 구조, 가중합 계층, Attention 계층 구현, seq2seq에 어텐션 추가, 어텐션 시각화

**3권** 밑바닥부터 시작하는 딥러닝 3 파이썬으로 직접 구현하며 배우는 딥러닝 프레임워크

- 1장 미분 자동계산 — DeZero 기반 마련 (단계 1~10)
  Variable·Function 클래스, 역전파 구조, 메모리 절약(순전파 모드), 복잡한 함수 미분

- 2장 자연스러운 코드 (단계 11~24)
  연산자 오버로딩, 변수 이름·형상, 파이썬 함수·클래스 활용, Define-by-Run, 계산 그래프 시각화

- 3장 2차 미분 계산 (단계 25~36)
  역전파의 역전파, 고차 미분, 테일러 급수, 뉴턴법, sin·cos·tanh

- 4장 신경망 만들기 (단계 37~51)
  Dataset·DataLoader, Layer·Linear·MLP 클래스, Optimizer(SGD·MomentumSGD), 파라미터 관리, 대형 데이터셋

- 5장 DeZero의 도전 (단계 52~60)
  GPU 대응(CuPy), 모델 저장·복원, CNN(Conv2D·Pooling), RNN·LSTM, 시계열·이미지 분류(VGG16)

**4권** 밑바닥부터 시작하는 딥러닝 4 직접 구현하며 익히는 강화 학습 알고리즘

- 1장 밴디트 문제
  슬롯머신 비유, 탐색과 활용 딜레마, ε-greedy, UCB 알고리즘

- 2장 마르코프 결정 과정 (MDP)
  상태·행동·보상, 전이 확률, 정책, 에피소드·반환

- 3장 벨만 방정식
  가치 함수(상태·행동), 벨만 기대 방정식, 벨만 최적 방정식

- 4장 동적 프로그래밍
  정책 평가, 정책 개선, 정책 반복법, 가치 반복법

- 5장 몬테카를로법
  MC 정책 평가, MC 제어, 오프-폴리시, 중요도 샘플링

- 6장 TD법
  TD(0), 살사(SARSA), Q-러닝, TD vs MC 비교

- 7장 딥러닝과 강화 학습
  함수 근사, Q-네트워크, DeZero·PyTorch, 과거 경험 재생

- 8장 DQN과 확장
  DQN 구현, 타깃 네트워크, Double DQN, Dueling DQN, 우선순위 재현

- 9장 정책 경사법
  REINFORCE, 기저선 빼기, Actor-Critic(A2C)

- 10장 심층 강화 학습의 미래
  A3C, DDPG(연속 행동), TRPO·PPO, 레인보우, 모방 학습, 전망

**5권** 밑바닥부터 시작하는 딥러닝 5 10단계로 익히는 이미지 생성 모델의 원리

- 1장 정규 분포
  가우스 분포 이론, 다변량 정규 분포, 파이썬 실습

- 2장 최대 가능도 추정 (MLE)
  가능도, 로그 가능도, MLE 실습, 분포 피팅

- 3장 가우스 혼합 모델 (GMM)
  혼합 분포, EM 알고리즘 개요

- 4장 기댓값 최대화 알고리즘 (EM)
  E-스텝·M-스텝, GMM에 EM 적용, 수렴 분석

- 5장 변이형 오토인코더 (VAE)
  오토인코더, ELBO, 재파라미터화 트릭, VAE 구현

- 6장 계층형 VAE
  잠재 변수 계층화, 다단계 인코더·디코더, HVAE 학습

- 7장 확산 모델 기초
  순방향 노이즈 추가 과정, 역방향 노이즈 제거, DDPM 원리

- 8장 확산 모델 구현
  U-Net 구조, 시간 임베딩, 학습 및 샘플링 코드

- 9장 개선된 확산 모델
  DDIM(결정론적 샘플링), 분류기 없는 안내(CFG), 조건부 생성

- 10장 확산 모델의 발전
  잠재 확산 모델(Stable Diffusion), 스코어 기반 생성, 최신 동향
