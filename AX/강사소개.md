# 01. 대학 강의 경력

## 컴퓨터공학의 기초부터 응용기술까지

대학에서는 프로그래밍 기초뿐 아니라 컴퓨터공학, 멀티미디어, 웹, 컴퓨터비전 등 다양한 분야를 교육해 왔습니다.

### 충북대학교

**2003.09 ~ 2019.08 / 약 16년**

* 컴퓨터공학 관련 과목 교육
* 컴퓨터공학의 기초 이론과 응용 분야 교육
* 전공 학생들의 프로그래밍 및 컴퓨터 시스템 이해를 위한 교육 수행 

### 대전과학기술대학교

**2018.03 ~ 2019.08**

* 자바프로그래밍
* 스마트프로그래밍 I
* 스마트프로그래밍 II 

### 청운대학교

**2002.03 ~ 2004.02 / 겸임교수**

* 자료구조
* 인터넷
* 멀티미디어 개론
* Windows Programming
* 멀티미디어 응용 및 실습 

### 기타 대학 강의

* **건국대학교**: 컴퓨터프로그래밍, 컴퓨터그래픽스, 컴퓨터애니메이션
* **한밭대학교**: 전자 CAD
* **우송대학교**: 전자 CAD

* **원광대학교**: Python, Excel, C 언어 

### 대학 교육의 특징

> **“이론을 이해하고, 프로그램으로 구현해 보는 교육”**

컴퓨터공학의 기초 이론부터 프로그래밍, 멀티미디어, 웹 기술까지 다양한 과목을 강의하면서 **학생이 어려운 기술을 쉽게 이해할 수 있도록 설명하는 것**을 중요하게 생각해 왔습니다.

강의 경험을 통해 단순히 많은 내용을 전달하는 것보다 학생이 내용을 **쉽게 이해하고 재미있게 학습할 수 있도록 하는 것이 중요하다**는 교육 방향을 갖게 되었습니다.

# 현재 교육의 핵심 방향

최근 교육에서는 기존의 **Java 기반 웹 개발**에서 더 나아가 **AI 기반 웹 서비스, 빅데이터 및 인공지능 분야**까지 교육 영역을 확대하고 있으며, 빠르게 변화하는 IT 기술에 대응하기 위해 지속적으로 새로운 기술을 학습하고 교육에 적용하고 있습니다. 

### ① 기초를 이해하는 개발자

단순히 코드를 암기하는 것이 아니라

**Computer → Network → Web → Programming → Database → AI**

가 서로 어떻게 연결되어 동작하는지를 이해합니다.

### ② AI를 사용할 수 있는 개발자

AI가 코드를 대신 작성하는 시대에는 코드를 직접 작성하는 능력뿐 아니라

**AI에게 요구 → 생성된 코드 이해 → 실행 → 오류 확인 → 수정 → 검증**

하는 능력이 중요합니다.

### ③ 프로젝트를 완성할 수 있는 개발자

교육의 최종 목표는 기술 하나를 배우는 것이 아니라,

**기획 → 설계 → 구현 → 테스트 → 배포 → 문서화**

까지 수행할 수 있는 개발자로 성장하는 것입니다.

### ④ 취업으로 연결되는 교육

개발 교육의 목표는 단순한 과정 수료가 아니라 **취업에 필요한 실무 역량과 프로젝트 경험을 확보하는 것**입니다.

이력서에서도 최근 교육의 목표를 재취업을 원하는 학습자들이 필요한 역량을 갖추고 원하는 분야에 취업할 수 있도록 지원하는 것으로 설명하고 있습니다.

# 수강생 여러분에게

이번 과정에서는 많은 기술을 배우게 됩니다.

하지만 **모든 기술을 처음부터 알고 시작할 필요는 없습니다.**

중요한 것은

**모르는 것을 확인하고 → 필요한 것을 학습하고 → 직접 만들어 보고 → 문제가 발생하면 해결하는 경험을 반복하는 것**입니다.

저 역시 대학에서 컴퓨터공학을 가르치는 것에서 출발하여 웹 개발, 데이터, 머신러닝·딥러닝 그리고 AI 서비스 개발 교육으로 교육 분야를 계속 확장해 왔습니다.

이번 과정에서도 여러분이 단순히 기술을 배우는 데 그치지 않고,

> **“AI를 활용하여 실제 서비스를 만들 수 있는 개발자”**

로 성장하고, 최종적으로 원하는 분야의 취업으로 연결할 수 있도록 함께 진행하겠습니다.
