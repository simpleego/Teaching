첨부된 **「AX 서비스 풀스택 빌더 과정」**의 교과 구성을 보면, 단순 프로그래밍 과정이 아니라 **서비스 기획 → FastAPI 백엔드 → RDB/ORM → REST API·인증 → React 프론트엔드 → AI 도구 활용 → LLM/RAG → CI/CD → 프로젝트**까지 연결되는 과정입니다. 특히 FastAPI 기반 백엔드와 데이터 흐름 이해가 요구되고 , RESTful API·JWT·OAuth2·Postman을 활용한 API 설계 및 검증 , React 기반 UI와 API 연동 , LLM·RAG·Function Calling까지 포함됩니다. 

따라서 OT 선수지식 평가는 단순 암기시험보다는 **“수업을 따라가기 위해 어느 부분의 보충이 필요한가”를 진단하는 형태**가 적합합니다. 아래처럼 **인터넷 기초 20문항 + 프로그래밍 기초 20문항 + AI 활용 설문 5문항**으로 구성하는 것을 권장합니다.

**1점 전혀 그렇지 않다 / 2점 그렇지 않다 / 3점 보통이다 / 4점 그렇다 / 5점 매우 그렇다**

| 20~22 | 활용  | AI와 반복적인 협업 가능         |
| 23~25 | 고활용 | AI 결과 검증·개선까지 능동적으로 수행 |

다만 이 점수는 **성적이나 선발 기준으로 사용하지 않고 교육 운영 참고자료**로 활용하는 것이 적절합니다.

# OT 평가 결과를 교육에 활용하는 방법

가장 중요한 것은 총점보다 **영역별 취약점**입니다. 다음과 같이 분류하면 수업 운영에 바로 사용할 수 있습니다.

| 진단 결과        | OT 이후 권장 보충                          |
| ------------ | ------------------------------------ |
| 인터넷 60점 미만   | IP, DNS, HTTP, Client/Server 집중 보충   |
| 인터넷 60~79점   | HTTP Method, 상태코드, JSON, REST API 보충 |
| 인터넷 80점 이상   | 정상 진도                                |
| 프로그래밍 60점 미만 | 변수·조건·반복·함수 Python 기초 보충             |
| 프로그래밍 60~79점 | List/Dict·함수·예외·코드 읽기 보충             |
| 프로그래밍 80점 이상 | FastAPI 학습 진입 가능                     |
| AI 설문 14점 이하 | 생성형 AI 기본 사용법 및 Prompt 기초 필요         |
| AI 설문 15~19점 | Prompt + 결과 검증 훈련                    |
| AI 설문 20점 이상 | AI-assisted coding 중심으로 진행 가능        |

특히 이 과정의 최종 목표가 **FastAPI·React·PostgreSQL·LangChain 기반 서비스를 CI/CD로 배포할 수 있는 수준의 스타터킷 구축**까지 이어지기 때문에 , OT에서부터 학생을 단순히 **“잘함/못함”**으로 나누기보다는 다음 세 축으로 프로파일링하는 방식이 효과적입니다.

**Web 이해도 / Programming 이해도 / AI 활용도**

예를 들어 학생별로 다음처럼 기록할 수 있습니다.

> 학생 A : Web 85 / Programming 55 / AI 22
> → 인터넷 이해와 AI 활용은 우수하나 Python 기초 보충 필요

> 학생 B : Web 45 / Programming 82 / AI 13
> → 프로그래밍 경험은 있으나 Web/HTTP 및 AI 활용 교육 필요

> 학생 C : Web 70 / Programming 72 / AI 18
> → 정상 진도 진행 가능

이렇게 하면 이후 **팀 프로젝트 구성 시에도 각 학생의 강점을 고려한 팀 배치 자료**로 활용할 수 있습니다. 기업 프로젝트 단계에서는 서비스 기획부터 풀스택 구조, LLM·RAG, 보안 반영, 문서화까지 통합적으로 수행해야 하므로 이러한 초기 진단의 활용도가 높습니다. 

**권장 OT 운영 순서는 `과정 소개 30분 → 선수지식 평가 50분 → 결과 자기진단 20분 → AI 활용 실습 60분 → 개발환경 점검 → 팀 활동` 정도로 구성하면 자연스럽습니다.**
