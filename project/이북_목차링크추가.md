요청하신 `.py` 확장자 파일로 생성했습니다.

[add_pdf_toc_links_bookmarks.py 다운로드](sandbox:/mnt/data/add_pdf_toc_links_bookmarks.py)

업로드하신 PDF처럼 앞부분 목차가 `순번 / 제목 / 페이지번호` 구조이고, 목차가 4~17페이지에 이어지는 형태를 기준으로 사용할 수 있게 작성했습니다. 

실행 예시는 다음과 같습니다.

```bash
pip install pymupdf
python add_pdf_toc_links_bookmarks.py input.pdf output_linked.pdf --toc-start 4 --toc-end 17
```

PART별 책갈피까지 명확히 지정하려면:

```bash
python add_pdf_toc_links_bookmarks.py input.pdf output_linked.pdf ^
  --toc-start 4 ^
  --toc-end 17 ^
  --part "PART 1 임신·출산·영유아:20:107" ^
  --part "PART 2 아동·청소년:108:195" ^
  --part "PART 3 시·군별 지원:196:999"
```
