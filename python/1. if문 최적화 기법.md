파이썬에서도 같은 개념으로 `if`를 단순화하거나, 아예 `if` 대신 **딕셔너리, 리스트, 집합(Set), 조건식, 함수 테이블** 등을 사용할 수 있습니다.

특히 주민번호처럼 **“특정 값 → 특정 결과”**가 명확한 문제는 `dict`를 사용하면 매우 깔끔해집니다.

## 1. 두 가지 선택이라면 조건 표현식

JavaScript의 삼항 연산자와 같은 역할입니다.

기본적인 `if ~ else`는 다음과 같습니다.

```python
if age >= 19:
    adult = "성년"
else:
    adult = "미성년"
```

파이썬에서는 한 줄로 표현할 수 있습니다.

```python
adult = "성년" if age >= 19 else "미성년"
```

형식은 다음과 같습니다.

```python
참일_때_값 if 조건 else 거짓일_때_값
```

예를 들어 성별도 가능합니다.

```python
gender = "여성" if gender_code in [0, 2, 4] else "남성"
```

조건이 **두 가지 결과 중 하나를 선택하는 경우**에 적합합니다.

# 2. 여러 값의 대응 관계라면 딕셔너리 `dict`

파이썬에서는 JavaScript의 Object보다 오히려 딕셔너리가 이런 용도에 더욱 자연스럽습니다.

예를 들어 주민번호 7번째 숫자와 성별의 관계가 다음과 같다고 합시다.

```text
0 → 여성
1 → 남성
2 → 여성
3 → 남성
4 → 여성
9 → 남성
```

조건문으로 만들면:

```python
if gender_code == 1:
    gender = "남성"
elif gender_code == 2:
    gender = "여성"
elif gender_code == 3:
    gender = "남성"
elif gender_code == 4:
    gender = "여성"
```

딕셔너리를 사용하면 훨씬 간단합니다.

```python
gender_table = {
    0: "여성",
    1: "남성",
    2: "여성",
    3: "남성",
    4: "여성",
    9: "남성"
}

gender = gender_table[gender_code]
```

핵심 개념은 다음과 같습니다.

```python
딕셔너리[키]
```

즉,

> 조건을 하나씩 검사하는 것이 아니라
> **키를 이용하여 결과를 바로 찾는 방식**입니다.

# 3. 출생 세기도 딕셔너리로 처리

일반적인 조건문이라면:

```python
birth_year = 2000 + year

if gender_code in [1, 2]:
    birth_year = 1900 + year

if gender_code in [0, 9]:
    birth_year = 1800 + year
```

딕셔너리를 이용하면:

```python
century_table = {
    0: 1800,
    1: 1900,
    2: 1900,
    3: 2000,
    4: 2000,
    9: 1800
}

birth_year = century_table[gender_code] + year
```

이 방식이 주민번호 문제에는 훨씬 직관적입니다.

```text
성별코드      기준연도

0      →      1800
1      →      1900
2      →      1900
3      →      2000
4      →      2000
9      →      1800
```

이 표를 그대로 딕셔너리에 옮긴 것입니다.

# 4. 띠처럼 반복되는 규칙은 리스트

띠는 12년마다 반복되므로 `if`보다 리스트가 훨씬 좋습니다.

```python
animals = [
    "원숭이",
    "닭",
    "개",
    "돼지",
    "쥐",
    "소",
    "호랑이",
    "토끼",
    "용",
    "뱀",
    "말",
    "양"
]

animal = animals[birth_year % 12] + "띠"

print(animal)
```

예를 들어:

```python
birth_year = 2000

print(birth_year % 12)
```

결과:

```text
8
```

그러므로

```python
animals[8]
```

은

```text
용
```

이 되고 최종적으로:

```text
용띠
```

가 됩니다.

즉,

```python
리스트[계산된_인덱스]
```

를 이용하면 많은 `if`를 제거할 수 있습니다.

# 5. 여러 값 중 하나인지 검사할 때 `in`

JavaScript의:

```javascript
[0, 2, 4].includes(genderCode)
```

와 비슷한 것이 파이썬의 `in`입니다.

기존 방식:

```python
if gender_code == 0 or gender_code == 2 or gender_code == 4:
    gender = "여성"
```

파이썬에서는:

```python
if gender_code in [0, 2, 4]:
    gender = "여성"
```

훨씬 읽기 쉽습니다.

그리고 조건 표현식과 결합하면:

```python
gender = "여성" if gender_code in [0, 2, 4] else "남성"
```

이렇게 만들 수 있습니다.

---

# 6. 리스트 대신 `set`을 사용할 수도 있음

포함 여부만 확인하는 경우 집합(Set)을 사용할 수 있습니다.

```python
female_codes = {0, 2, 4}

gender = "여성" if gender_code in female_codes else "남성"
```

이 코드는 상당히 자연스럽습니다.

```python
female_codes = {0, 2, 4}
```

는 다음 의미입니다.

> 여성에 해당하는 코드들의 집합

그리고:

```python
gender_code in female_codes
```

는

> `gender_code`가 여성 코드 집합에 들어 있는가?

라는 의미입니다.

# 7. `match ~ case`로 여러 조건 처리

Python 3.10 이상에서는 `match ~ case`를 사용할 수 있습니다.

JavaScript의 `switch`와 비슷합니다.

```python
match gender_code:

    case 1 | 3 | 9:
        gender = "남성"

    case 0 | 2 | 4:
        gender = "여성"

    case _:
        gender = "확인 불가"
```

여기에서:

```python
case 1 | 3 | 9:
```

는

```text
1 또는 3 또는 9
```

라는 의미입니다.

하지만 주민번호 성별처럼 단순히 대응값을 찾는 문제라면 개인적으로는 `dict`가 더 적합합니다.

```python
gender_table = {
    0: "여성",
    1: "남성",
    2: "여성",
    3: "남성",
    4: "여성",
    9: "남성"
}

gender = gender_table[gender_code]
```

# 8. 잘못된 키에 대비하려면 `dict.get()`

딕셔너리에서 존재하지 않는 키를 사용하면 오류가 발생합니다.

```python
gender = gender_table[7]
```

만약 `7`이라는 키가 없다면:

```text
KeyError
```

가 발생합니다.

그래서 실제 프로그램에서는 `get()`을 많이 사용합니다.

```python
gender = gender_table.get(
    gender_code,
    "확인 불가"
)
```

의미는:

```text
gender_code가 있으면 해당 값 반환
없으면 "확인 불가" 반환
```

입니다.

예:

```python
gender_table = {
    1: "남성",
    2: "여성"
}

print(gender_table.get(1, "확인 불가"))
print(gender_table.get(7, "확인 불가"))
```

결과:

```text
남성
확인 불가
```

수업에서 상당히 유용한 패턴입니다.

# 9. 지역 정보도 딕셔너리로 처리 가능

예를 들어 간단한 지역 코드를 다음처럼 사용할 수 있습니다.

```python
region_table = {
    0: "서울",
    1: "서울",
    2: "서울",
    9: "부산",
    10: "부산",
    13: "인천",
    40: "대전",
    65: "광주"
}
```

그리고:

```python
region = region_table.get(
    region_code,
    "지역 확인 어려움"
)
```

라고 할 수 있습니다.

하지만 지역번호처럼 **범위**로 구성된 경우에는 딕셔너리 하나만으로 처리하기가 조금 불편합니다.

예를 들어:

```text
00~08 → 서울
09~12 → 부산
13~15 → 인천
16~25 → 경기
```

이런 경우에는 `if`가 오히려 자연스러울 수도 있습니다.

```python
region = "확인 어려움"

if 0 <= code <= 8:
    region = "서울"

if 9 <= code <= 12:
    region = "부산"

if 13 <= code <= 15:
    region = "인천"
```

즉, **무조건 if를 없애는 것이 좋은 코드는 아닙니다.**

# 10. 범위 데이터도 자료구조로 바꿀 수 있음

조금 더 발전시키면 지역 범위 자체를 데이터로 저장할 수 있습니다.

```python
regions = [
    (0, 8, "서울"),
    (9, 12, "부산"),
    (13, 15, "인천"),
    (16, 25, "경기"),
    (26, 34, "강원"),
    (35, 39, "충북")
]
```

각 데이터의 의미는:

```text
시작번호, 끝번호, 지역
```

입니다.

반복문을 이용하면:

```python
region = "확인 어려움"

for start, end, name in regions:

    if start <= region_code <= end:
        region = name
        break
```

이 경우 `if`는 남아 있지만 중요한 변화가 있습니다.

기존:

```python
if ...
if ...
if ...
if ...
if ...
```

에서

```python
데이터 + 반복문 + 하나의 if
```

로 바뀝니다.

실제 프로그램에서는 이런 구조가 유지보수에 더 좋습니다.

# 11. 별자리도 데이터 중심으로 설계 가능

초급 단계에서는 보통 이렇게 작성할 수 있습니다.

```python
if month == 1 and day >= 20:

elif month == 2 and day <= 18:
    star = "물병자리"
```

하지만 별자리 기준도 데이터로 저장할 수 있습니다.

예:

```python
stars = [
    (120, "염소자리"),
    (219, "물병자리"),
    (321, "물고기자리"),
    (420, "양자리"),
    (521, "황소자리"),
    (622, "쌍둥이자리"),

    (1023, "천칭자리"),
    (1123, "전갈자리"),

```

월과 일을 숫자로 합칩니다.

# 12. 함수 자체를 딕셔너리에 저장

파이썬에서도 함수는 변수에 저장할 수 있습니다.

```python
def show_gender():
    return "성별 계산"


def show_zodiac():
    return "띠 계산"


def show_star():
    return "별자리 계산"
```

딕셔너리에 저장하면:

```python
commands = {
    "gender": show_gender,
    "zodiac": show_zodiac,
    "star": show_star
}
```

사용:

```python
print(commands["gender"]())
```

결과:

```text
성별 계산
```

이것은 나중에 상당히 중요한 구조가 됩니다.

예를 들어:

```python
commands = {
    "회원가입": signup,
    "로그인": login,
    "주문": order,
    "결제": payment
}
```

처럼 만들 수 있습니다.

웹 개발에서는 URL이나 명령에 따라 함수를 선택하는 구조로 발전할 수 있습니다.

```python
commands = {
```

# 14. 유효성 검사는 오히려 `if + return`이 좋음

`if`를 모두 없애려고 하면 코드가 오히려 복잡해질 수 있습니다.

예를 들어 주민번호 검사에서는:

```python
if len(jumin) != 13:
    print("13자리를 입력하세요.")
    return
```

또는:

```python
if not jumin.isdigit():
    print("숫자만 입력하세요.")
    return
```

날짜가 잘못됐다면:

```python
if not valid_date:
    print("잘못된 날짜입니다.")
    return
```

이런 코드는 매우 좋습니다.

이를 **Guard Clause** 또는 **Early Return**이라고 합니다.

흐름을 보면:

```text
잘못된 입력인가?
       ↓ YES
   즉시 종료

       ↓ NO
다음 단계 진행
```

입니다.

이 경우에는 `if`가 가장 좋은 도구입니다.

# 15. 주민번호 예제의 추천 방식

| 처리 내용       | Python 추천 방법    |
| ----------- | --------------- |
| 성년 / 미성년    | 조건 표현식          |
| 성별          | `dict`          |
| 출생 세기       | `dict`          |
| 띠           | `list + %`      |
| 여러 코드 포함 여부 | `in`            |
| 코드 집합       | `set`           |
| 별자리         | `if` 또는 데이터 테이블 |
| 지역 범위       | 리스트 + 반복문       |
| 유효성 검사      | `if + return`   |
| 명령 처리       | `dict + 함수`     |

# 수업에서는 다음 순서가 좋습니다

```text
1단계
if ~ else
```

↓

```text
2단계
기본값 + if
```

↓

```text
3단계
조건 표현식

값1 if 조건 else 값2
```

↓

```text
4단계
in

값 in [값1, 값2, 값3]
```

↓

```text
5단계
list

순서 → 값
```

↓

```text
6단계
dict

키 → 값
```

↓

```text
7단계
set

값의 포함 여부
```

↓

```text
8단계
dict + function

키 → 처리 함수
```

이 과정을 통해 학생들에게 중요한 개념을 설명할 수 있습니다.

> **초급자는 조건을 하나씩 검사하고, 숙련자는 규칙을 데이터로 표현하는 방법을 생각한다.**

예를 들어 초급 단계에서는:

```python
if code == 1:
    gender = "남성"

elif code == 2:
    gender = "여성"

elif code == 3:
    gender = "남성"
```

라고 생각하지만, 한 단계 발전하면:

```python
gender_table = {
    1: "남성",
    2: "여성",
    3: "남성"
}

gender = gender_table[code]
```

라고 생각할 수 있습니다.

이 차이가 상당히 중요합니다. **조건 로직을 자료구조로 전환하는 사고**는 이후 Python의 JSON 처리, API 응답, 데이터베이스 조회, FastAPI 라우팅, 설정 파일, AI Agent의 Tool 선택 구조까지 자연스럽게 연결됩니다.
