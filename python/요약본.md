파이썬 기초부터 고급 문법까지, **성적표 / 자판기 / 계산기** 3가지 예제 프로그램으로 관통해서 설명할게.

# 1. 데이터와 데이터형 그리고 변수

**개념:** 변수는 값을 담는 이름표. 파이썬은 타입을 선언하지 않고 대입 시점에 결정됨(동적 타이핑).

```python
# 성적표 프로그램 - 데이터 입력
name = "철수" # str
kor, eng, math = 90, 85, 95 # int
avg = (kor + eng + math) / 3 # float

# 자료형 확인
print(type(name), type(avg))

# 리스트, 딕셔너리 활용
scores = [90, 85, 95]
student = {"이름": "철수", "평균": 90.0}
```

**포인트:** `int, float, str, bool`는 기본형, `list, dict, tuple, set`은 컨테이너. 성적표처럼 묶음 데이터는 리스트/딕셔너리로 관리.

# 2. 연산자

**개념:** 값에 대한 계산과 비교, 논리 판단 도구.

```python
# 계산기 프로그램 - 사칙연산
a, b = 10, 3
print(a + b, a - b, a * b, a / b) # 13 7 30 3.333...
print(a // b, a % b, a ** b) # 몫 3, 나머지 1, 거듭제곱 1000

# 자판기 프로그램 - 비교/논리 연산자
money = 1500
price = 1200
can_buy = money >= price and price > 0 # True
print("구매 가능:", can_buy)
print("거스름돈:", money - price if can_buy else 0)
```

**포인트:** `// % **`는 파이썬 특유. `and or not`으로 조건 조합.

# 3. 제어문

**개념:** 조건에 따른 분기(`if`), 반복(`for`, `while`).

```python
# 성적표 - 학점 판정
avg = 88.5
if avg >= 90:
    grade = "A"
elif avg >= 80:
    grade = "B"
else:
    grade = "C"
print(f"평균 {avg}, 학점 {grade}")

# 자판기 - 재고 반복 처리
drinks = ["콜라", "사이다", "커피"]
for i, d in enumerate(drinks, 1):
    print(f"{i}. {d}")

# 계산기 - while로 계속 실행
while True:
    cmd = input("계산 계속? (y/n): ")
    if cmd == "n":
        break
    print("계산 중...")
```

# 4. 함수, 파일 입출력

**개념:** 함수는 재사용 단위. 파일 입출력으로 데이터 영속화.

```python
# 성적표 함수화
def calc_avg(scores):
    """평균 계산"""
    return sum(scores) / len(scores)

def get_grade(avg):
    return "A" if avg>=90 else "B" if avg>=80 else "C"

# 파일 저장/읽기
student_info = f"철수,{calc_avg([90,85,95]):.1f},{get_grade(90)}"

with open("report.txt", "w", encoding="utf-8") as f:
    f.write(student_info)

with open("report.txt", "r", encoding="utf-8") as f:
    print(f.read()) # 철수,90.0,A

# 가변인자 계산기
def calc(op, *nums):
    if op == "+": return sum(nums)
    if op == "*":
        r = 1
        for n in nums: r *= n
        return r
print(calc("+", 1,2,3,4)) # 10
```

# 5. 클래스, 모듈, 패키지

**개념:** 클래스는 데이터+함수의 설계도. 모듈은.py 파일, 패키지는 모듈 폴더.

```python
# 자판기 클래스
class VendingMachine:
    def __init__(self):
        self.money = 0
        self.menu = {"콜라":1200, "사이다":1000}

    def insert(self, amount):
        self.money += amount

    def buy(self, name):
        price = self.menu[name]
        if self.money >= price:
            self.money -= price
            return f"{name} 나옴, 잔액 {self.money}"
        return "잔액 부족"

vm = VendingMachine()
vm.insert(2000)
print(vm.buy("콜라"))

# 모듈 사용 예 (별도 파일 mycalc.py가 있다고 가정)
# from mycalc import calc_avg
# import math as m
# print(m.sqrt(16))
```

**포인트:** `__init__`은 생성자, `self`는 자기 자신. 큰 프로젝트는 `shop/vending.py`처럼 패키지로 나눔.

# 6. 예외처리

**개념:** 에러 발생 시 프로그램 중단 대신 대응.

```python
# 계산기 - 0으로 나누기 대응
def safe_div(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "0으로 나눌 수 없어요"
    except TypeError:
        return "숫자를 입력하세요"
    finally:
        print("계산 시도 완료")

print(safe_div(10, 0))
print(safe_div(10, "a"))

# 자판기 - 없는 메뉴 처리
try:
    vm.buy("환타")
except KeyError:
    print("없는 메뉴입니다")
```

# 8. 클로저, 데코레이터, 제너레이터, 타입 애너테이션

**개념:** 고급 함수 활용법. 실무 코드의 핵심.

**클로저:** 함수를 기억하는 함수
```python
def discount_maker(rate):
    def apply(price: int) -> int: # 타입 애너테이션
        return int(price * (1 - rate))
    return apply

vip_dc = discount_maker(0.2)
print(vip_dc(10000)) # 8000, rate=0.2를 기억
```

**데코레이터:** 함수에 기능 덧씌우기
```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        s = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 실행시간: {time.time()-s:.4f}s")
        return result
    return wrapper

@timer
def calc_avg_big(scores: list[int]) -> float:
    time.sleep(0.1)
    return sum(scores)/len(scores)

print(calc_avg_big([90]*1000))
```

**제너레이터:** 메모리 절약 반복
```python
def report_gen(students):
    for name, scores in students:
        yield f"{name}: {sum(scores)/len(scores):.1f}점"

students = [("철수",[90,80]), ("영희",[95,100])]
for r in report_gen(students):
    print(r)
# 리스트가 아닌 필요할 때 하나씩 생성
```

이 8단계를 성적표(데이터 처리) → 자판기(클래스/상태) → 계산기(함수/예외) 흐름으로 직접 코딩해보면 개념이 바로 체득돼. 다음으로 어떤 예제를 직접 완성해볼까?
