# 다중상속
> 파이썬은 클래스 정의 시 **부모 클래스를 여러 개 나열하면 그대로 다중상속이 된다.**

---

## 🟦 파이썬은 다중상속을 지원한다  
파이썬 클래스 정의는 다음처럼 부모 클래스를 여러 개 넣을 수 있어:

```python
class Child(Parent1, Parent2):
    pass
```

자바는 단일 상속만 가능하지만, 파이썬은 **여러 부모 클래스의 기능을 모두 물려받을 수 있다.**

---

## 🟩 다중상속 기본 예시  
```python
class A:
    def hello(self):
        return "A의 hello"

class B:
    def world(self):
        return "B의 world"

class C(A, B):
    pass

obj = C()
print(obj.hello())  # A의 hello
print(obj.world())  # B의 world
```

C는 A와 B의 모든 메서드를 그대로 상속받는다.

---

## 🟧 메서드 충돌 시: MRO(Method Resolution Order)  
다중상속에서 가장 중요한 개념은 **MRO(메서드 탐색 순서)**야.

파이썬은 **C3 Linearization**이라는 알고리즘을 사용해서  
“어떤 부모 클래스의 메서드를 먼저 사용할지”를 결정한다.

### ✔ 예시: 부모 클래스가 같은 이름의 메서드를 가질 때

```python
class A:
    def greet(self):
        return "A"

class B:
    def greet(self):
        return "B"

class C(A, B):
    pass

print(C().greet())  # A
```

부모 순서가 `(A, B)`이므로 A의 메서드가 먼저 선택된다.

### ✔ MRO 확인

```python
print(C.__mro__)
```

출력 예:

```
(<class '__main__.C'>, <class '__main__.A'>, <class '__main__.B'>, <class 'object'>)
```

## 🟨 super()는 다중상속에서도 안전하게 동작  
파이썬의 `super()`는 자바보다 훨씬 강력해.  
다중상속에서도 MRO 순서를 따라 안전하게 부모 메서드를 호출한다.

```python
class A:
    def greet(self):
        return "A"

class B(A):
    def greet(self):
        return "B -> " + super().greet()

class C(B):
    def greet(self):
        return "C -> " + super().greet()

print(C().greet())
```

출력:

```
C -> B -> A
```

## 🟪 다중상속 + 믹스인(Mixin) 패턴  
파이썬에서 다중상속은 **믹스인(Mixin)** 패턴으로 자주 사용된다.

### ✔ 믹스인 예시

```python
class LogMixin:
    def log(self, msg):
        print(f"[LOG] {msg}")

class SaveMixin:
    def save(self):
        print("저장 완료")

class User(LogMixin, SaveMixin):
    pass

u = User()
u.log("사용자 생성")
u.save()
```

믹스인은 “기능을 추가하는 작은 클래스”로 다중상속의 대표적인 활용 방식이다.

---

## 🟥 다중상속의 주의점  
파이썬은 다중상속을 지원하지만, 다음을 주의해야 해:

### ✔ 1) 메서드 충돌  
부모 클래스들이 같은 이름의 메서드를 가지면 MRO 순서에 따라 결정되지만,  
설계가 복잡해질 수 있다.

### ✔ 2) 지나친 다중상속은 유지보수 어려움  
믹스인처럼 “작은 기능 조각”을 조합하는 방식이 가장 바람직하다.

---

## 🟦 결론

### ✔ 믹스인 패턴으로 실무에서 매우 자주 사용된다
