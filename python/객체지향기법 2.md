jong, 파이썬에서 **자바의 객체지향 핵심 개념(클래스, 상속, 추상화, 인터페이스, 다형성)**을 어떻게 표현하는지 **개념 + 코드 + 시각적 이해**까지 한 번에 정리해줄게.  
파이썬은 자바와 철학이 달라서(동적 언어, 프로토콜 기반), 같은 개념을 **더 유연한 방식**으로 구현해.  
아래는 “자바 개발자가 파이썬 OOP를 이해할 때 가장 도움이 되는 구조”로 정리한 내용이야.

---

# 🧱 1. 클래스(Class)  
파이썬 클래스는 자바와 거의 동일하지만, 생성자 이름이 `__init__`이고, `self`를 명시적으로 사용한다.





### ✔ 개념  
- 객체를 생성하는 설계도  
- 속성(변수) + 메서드(함수) 포함  
- 파이썬은 모든 것이 객체

### ✔ 코드 예시
```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name}가 소리를 냅니다."

dog = Animal("강아지")
print(dog.speak())
```

---

# 🧱 2. 상속(Inheritance)  
파이썬은 자바처럼 `extends`가 없고, 클래스 정의 시 괄호 안에 부모 클래스를 넣는다.





### ✔ 개념  
- 부모 클래스의 기능을 자식 클래스가 물려받음  
- 메서드 오버라이딩 가능

### ✔ 코드 예시
```python
class Animal:
    def speak(self):
        return "소리를 냅니다."

class Dog(Animal):
    def speak(self):
        return "멍멍!"

class Cat(Animal):
    def speak(self):
        return "야옹!"

animals = [Dog(), Cat()]
for a in animals:
    print(a.speak())
```

---

# 🧱 3. 추상화(Abstraction)  
파이썬은 자바처럼 강제적인 추상 클래스가 없지만, `abc` 모듈로 동일한 기능을 제공한다.





### ✔ 개념  
- 공통 인터페이스만 정의하고 구현은 자식 클래스가 담당  
- `@abstractmethod`로 구현 강제

### ✔ 코드 예시
```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "멍멍!"

# Animal()  # ❌ 추상 클래스는 직접 생성 불가
```

---

# 🧱 4. 인터페이스(Interface)  
파이썬에는 자바처럼 인터페이스 문법이 없다.  
대신 **추상 클래스 + 추상 메서드** 또는 **덕 타이핑(duck typing)**으로 인터페이스 역할을 수행한다.





### ✔ 방식 1: 추상 클래스 기반 인터페이스
```python
from abc import ABC, abstractmethod

class Flyable(ABC):
    @abstractmethod
    def fly(self):
        pass

class Bird(Flyable):
    def fly(self):
        return "새가 날아갑니다."
```

### ✔ 방식 2: 덕 타이핑(Duck Typing)  
“오리가 걷고 꽥꽥하면 오리다” → 타입보다 **행동(메서드 존재)**이 중요.

```python
class Bird:
    def fly(self):
        return "새가 날아요"

class Plane:
    def fly(self):
        return "비행기가 날아요"

def go_fly(obj):
    print(obj.fly())  # fly()만 있으면 어떤 객체든 OK

go_fly(Bird())
go_fly(Plane())
```

---

# 🧱 5. 다형성(Polymorphism)  
파이썬은 다형성이 **언어 자체에 자연스럽게 녹아있다.**  
상속 기반 다형성 + 덕 타이핑 기반 다형성 모두 지원.





### ✔ 상속 기반 다형성
```python
class Animal:
    def speak(self):
        return "소리"

class Dog(Animal):
    def speak(self):
        return "멍멍"

class Cat(Animal):
    def speak(self):
        return "야옹"

def make_sound(animal: Animal):
    print(animal.speak())

make_sound(Dog())
make_sound(Cat())
```

### ✔ 덕 타이핑 기반 다형성
```python
class Robot:
    def speak(self):
        return "삐빅"

make_sound(Robot())  # Animal 상속 안 해도 OK
```

# 🧱 6. 캡슐화(Encapsulation)  
파이썬은 자바처럼 강한 접근 제어자가 없다.  
대신 **관례 기반**으로 캡슐화를 표현한다.





### ✔ 방식  
- `_변수` : protected 느낌  
- `__변수` : private 느낌 (name mangling)

### ✔ 코드 예시
```python
class Person:
    def __init__(self, name):
        self._age = 20        # 관례상 보호됨
        self.__secret = "비밀"  # private처럼 동작

p = Person("홍길동")
print(p._age)
# print(p.__secret)  # ❌ 에러
print(p._Person__secret)  # 내부적으로는 이렇게 저장됨
```

# 🧱 7. 정적 메서드 / 클래스 메서드  
자바의 static 메서드와 유사한 기능.





### ✔ 코드 예시
```python
class MathUtil:
    @staticmethod
    def add(a, b):
        return a + b

    @classmethod
    def description(cls):
        return f"{cls.__name__} 클래스입니다."

print(MathUtil.add(3, 5))
print(MathUtil.description())
```

# 🧱 8. 파이썬 OOP의 핵심 철학 (자바와 비교)

| 개념 | 자바 | 파이썬 |
|------|------|--------|
| 타입 중심 | 강한 타입 | 행동 중심(덕 타이핑) |
| 인터페이스 | 명시적 | 암묵적(추상 클래스 또는 메서드 존재 여부) |
| 접근 제어 | 강제(private, protected) | 관례 기반(_변수, __변수) |
| 다형성 | 상속 기반 | 상속 + 덕 타이핑 |
| 추상화 | 명시적 | abc 모듈로 구현 |
