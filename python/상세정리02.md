좋아, 아까 8챕터를 **3단계 깊이**로 확장해서 실무 교재 수준으로 다시 정리해줄게. 각 챕터 = 개념 → 문법 디테일 → 실전 예제 구조로 간다.

### 전체 로드맵
> 성적표(데이터/제어) → 자판기(클래스/예외) → 계산기(고급문법) 3개 프로젝트가 챕터가 갈수록 진화함

## 1. 데이터와 데이터형 그리고 변수

#### 1.1 변수의 본질
변수는 값을 저장하는 박스가 아니라 **객체를 가리키는 이름표**다. `id()`와 `is`로 확인 가능.
```python
a = [1,2,3]
b = a # 같은 객체를 가리킴
b.append(4)
print(a) # [1,2,3,4] -> a도 바뀐다
print(id(a) == id(b)) # True
```
- **동적 타이핑:** 타입 선언 없이 대입 시점에 결정
- **가변/불변:** `int, str, tuple`은 불변, `list, dict, set`은 가변

#### 1.2 핵심 데이터형 상세
**1.2.1 시퀀스:** 순서가 있음
- `str`: `"철수"[0]`, 슬라이싱 `"hello"[1:4]`
- `list`: `[90][80][70]` 수정/추가 가능
- `tuple`: `(90,80)` 패킹/언패킹 `kor, eng = (90,80)`

**1.2.2 매핑/집합:** 순서보다 키/중복
- `dict`: `{"국어":90, "영어":80}` - 성적표 최적
- `set`: `{90, 80, 90}` → `{90,80}` 중복 제거

#### 1.3 실전: 성적표 데이터 모델링
```python
# 3단계 중첩 구조 - 가장 많이 쓰는 형태
student = {
    "이름": "김파이",
    "학번": "2026001",
    "성적": {"국어": 85, "영어": 90, "수학": 78},
    "이수": {"국어", "영어"} # set으로 이수과목 관리
}
print(student["성적"]["국어"])
```

## 2. 연산자

#### 2.1 연산자 3분류
1. **산술:** `+ - * / // % **`
2. **비교/논리:** `==!= > <`, `and or not`
3. **특수:** `in, is, :=` (walrus 연산자)

#### 2.2 연산자 우선순위와 단축평가
```python

```

3. **매직 메서드:** `__init__, __str__, __len__`

#### 5.2 객체지향 3원칙 적용
```python
class Drink: # 부모 클래스
    def __init__(self, name, price):
        self.name = name
        self.price = price
    def __str__(self):
        return f"{self.name}({self.price}원)"

class VendingMachine: # 자판기는 Drink를 포함(Composition)
    def __init__(self):
        self._balance = 0 # _는 private 관례
        self.drinks = [Drink("콜라",1500), Drink("사이다",1300)]

    @property # getter처럼 사용
    def balance(self):
        return self._balance

    def insert(self, money):
        self._balance += money

# 상속 예시: 프리미엄 자판기
class PremiumVending(VendingMachine):
    def event_buy(self, name): # 메서드 오버라이딩
        print("이벤트! 10% 할인")
        return super().buy(name)
```

def safe_buy(vm, name, stock):
    try:
        if stock[name] == 0:
            raise ValueError(f"{name} 품절")

## 8. 클로저, 데코레이터, 제너레이터, 타입 애너테이션

#### 8.1 클로저 - 상태를 기억하는 함수
```python
def make_discount(rate: float):
    # rate를 기억하는 클로저
    def discount(price: int) -> int:
        return int(price * (1 - rate))
    return discount

vip = make_discount(0.3)
print(vip(10000)) # 7000
```

#### 8.2 데코레이터 - 함수 확장 공장
```python
from functools import wraps
import time

def login_required(func):
    @wraps(func) # 원본 함수 정보 유지
    def wrapper(user, *args, **kwargs):
        if not user.get("is_login"):
            raise PermissionError("로그인 필요")
        return func(user, *args, **kwargs)
    return wrapper

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__}: {time.time()-start:.4f}s")
        return res
    return wrapper

@login_required
@timer # 데코레이터 중첩 - 아래부터 위로 실행
def buy_premium(user, drink):
    print(f"{drink} 구매")
    return True

user = {"name":"김파이", "is_login": True}
buy_premium(user, "콜라")
```

#### 8.3 제너레이터 & 타입 애너테이션 - 최종 계산기
```python
from typing import Generator, List

def score_reader(file_path: str) -> Generator[int, None, None]:
    """대용량 성적 파일을 한 줄씩 읽기 - 메모리 절약"""
    with open(file_path, "r", encoding="utf-8") as f:
        for line in f:
            try:
                yield int(line.strip())
            except ValueError:
                continue # 숫자 아닌 줄은 스킵

# 타입이 명시된 고급 계산기
class Calc:
    def __init__(self) -> None:
        self.history: List[str] = []

    @timer
    def calc(self, op: str, *nums: float) -> float:
        if op == "+": res = sum(nums)
        elif op == "*":
            res = 1
            for n in nums: res *= n
        else: raise ValueError("지원 안 함")
        self.history.append(f"{op} {nums} = {res}")
        return res

calc = Calc()
print(calc.calc("+", 1,2,3,4,5))
```
