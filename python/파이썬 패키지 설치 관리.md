아래는 **`requirements.txt`를 사용하는 pip 설치 방법**을 **실무 기준**으로 정리한 설명입니다.
(입문 → 협업 → 운영 환경까지 자연스럽게 이어지도록 구성했습니다)

---

## 1️⃣ `requirements.txt`란?

> **파이썬 프로젝트가 의존하는 패키지 목록을 고정·공유하는 파일**

* 팀원 / 서버 / CI 환경에서 **동일한 실행 환경 보장**
* `pip install`을 **한 줄로 재현 가능**

---

## 2️⃣ 가장 기본적인 사용법

### 📌 1) `requirements.txt` 예시

```txt
numpy
pandas
opencv-python
fastapi
uvicorn
```

### 📌 2) 설치 명령

```bash
pip install -r requirements.txt
```

👉 의미

* `-r` : **requirements 파일 읽기(read)**
* pip이 **위에서 아래로** 패키지 설치

---

## 3️⃣ 버전 고정 방식 (중요 ⭐)

### ✔ 정확한 버전 고정 (완전 재현)

```txt
numpy==1.26.4
pandas==2.1.4
```

* 서버/배포 환경에서 **강력 추천**
* 재현성 100%

---

### ✔ 최소 버전만 지정

```txt
fastapi>=0.110.0
```

* 최신 기능 허용
* 예기치 않은 버전 충돌 가능

---

### ✔ 범위 지정

```txt
torch>=2.1,<2.3
```

* 안정성과 유연성의 절충안

---

## 4️⃣ 현재 환경에서 `requirements.txt` 생성하기

### 📌 현재 설치된 패키지 저장

```bash
pip freeze > requirements.txt
```

⚠ 주의

* **불필요한 패키지까지 전부 저장됨**
* 가상환경(venv) 안에서 실행 권장

---

## 5️⃣ 가상환경(venv)과 함께 쓰는 표준 흐름 ⭐⭐⭐

```bash
# 1. 가상환경 생성
python -m venv venv

# 2. 활성화
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

# 3. 패키지 설치
pip install -r requirements.txt
```

👉 **절대 시스템 Python에 바로 설치하지 않는 것**이 실무 관례

---

## 6️⃣ 주석, 옵션, 조건 사용법

### ✔ 주석

```txt
# Core
numpy==1.26.4
pandas==2.1.4

# Vision
opencv-python>=4.9
```

---

### ✔ OS 조건 분기

```txt
pywin32; sys_platform == "win32"
```

---

### ✔ Python 버전 조건

```txt
tensorflow; python_version >= "3.9"
```

---

## 7️⃣ 파일 분리 전략 (실무)

```txt
requirements.txt        # 공통
requirements-dev.txt    # 개발용
requirements-prod.txt   # 배포용
```

### 예시

```txt
# requirements-dev.txt
-r requirements.txt
pytest
black
```

```bash
pip install -r requirements-dev.txt
```

---

## 8️⃣ 자주 발생하는 오류 & 해결

### ❌ `ERROR: Could not find a version that satisfies...`

* Python 버전과 패키지 요구사항 불일치
* 해결:

```bash
python --version
pip install 패키지명 --upgrade
```

---

### ❌ `subprocess-exited-with-error`

* 컴파일 필요 패키지 (scipy, torch 등)
* 해결:

```bash
pip install --upgrade pip setuptools wheel
```

## 9️⃣ 실무 권장 베스트 프랙티스 요약

| 항목     | 권장                  |
| ------ | ------------------- |
| 가상환경   | 반드시 사용              |

| freeze | venv 안에서            |
| 파일 분리  | dev / prod          |
| 공유     | requirements.txt 포함 |
