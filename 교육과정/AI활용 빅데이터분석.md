# 생성형 AI 빅데이터 분석 과정

---

### 📅 3개월 생성형 AI 빅데이터 분석 과정 커리큘럼 (비전공자 대상)

#### **1개월차: 기초 다지기 & 데이터 분석 입문**
목표: 프로그래밍과 데이터 분석의 기본기를 탄탄히 다지고, 생성형 AI를 업무에 활용하는 방법을 익힌다.

| 주차 | 주요 학습 내용 | 상세 실습 및 활동 |
| :--- | :--- | :--- |
| **1주** | **오리엔테이션 & 환경 설정** | - 과정 및 진로 로드맵 소개<br>- 개발 환경 구축 (Python, Jupyter Notebook, VS Code)<br>- **생성형 AI (ChatGPT, Claude 등) 활용법**: 프롬프트 엔지니어링 기초, 코딩 도우미로 활용하기 |
| **2주** | **Python 프로그래밍 기초 (1)** | - 변수, 데이터 타입, 조건문, 반복문<br>- 함수, 모듈, 패키지 이해<br>- 생성형 AI를 활용한 코드 작성 및 디버깅 실습 |
| **3주** | **Python 프로그래밍 기초 (2)** | - **데이터 분석 필수 라이브러리**: NumPy (수치 연산), Pandas (데이터 처리) 기초<br>- CSV, Excel 등 다양한 데이터 파일 불러오기 및 저장하기 |
| **4주** | **데이터 시각화 기초** | - **시각화 라이브러리**: Matplotlib, Seaborn을 활용한 기본 차트 그리기 (막대, 선, 산점도 등)<br>- 데이터의 분포와 관계를 시각적으로 이해하는 훈련 |

---

#### **2개월차: 빅데이터 분석 & 머신러닝 심화**
목표: 방대한 데이터를 다루는 방법을 익히고, 머신러닝 모델을 직접 구현하며 생성형 AI로 분석을 자동화한다.

| 주차 | 주요 학습 내용 | 상세 실습 및 활동 |
| :--- | :--- | :--- |
| **5주** | **데이터 전처리 & 탐색적 데이터 분석(EDA)** | - Pandas를 활용한 데이터 클렌징 (결측치, 이상치 처리)<br>- **EDA 실습**: 실제 데이터셋을 탐색하며 인사이트 도출<br>- 생성형 AI로 데이터 리포팅 자동화 |
| **6주** | **머신러닝 기초 (1)** | - 머신러닝 개념 (지도/비지도 학습, 회귀/분류)<br>- **대표 알고리즘**: 선형 회귀, 로지스틱 회귀, 의사결정나무 학습 및 구현 |
| **7주** | **머신러닝 기초 (2) & 모델 평가** | - **모델 성능 평가**: 정확도, 정밀도, 재현율, F1-score 등<br>- 교차 검증, 하이퍼파라미터 튜닝 기초<br>- 생성형 AI를 활용한 머신러닝 코드 최적화 |
| **8주** | **데이터베이스 & 빅데이터 기초** | - SQL 기초 (데이터 조회, 필터링, 그룹화)<br>- 대용량 데이터 처리의 필요성 이해<br>- 클라우드(AWS, GCP) 빅데이터 서비스 개론 |

---

#### **3개월차: 생성형 AI 활용 & 종합 프로젝트**
목표: 배운 모든 기술을 종합하여 생성형 AI 기반의 빅데이터 분석 서비스를 기획하고, 실무 수준의 프로젝트를 완성한다.

| 주차 | 주요 학습 내용 | 상세 실습 및 활동 |
| :--- | :--- | :--- |
| **9주** | **딥러닝 & 생성형 AI 입문** | - 딥러닝 기본 개념 (인공신경망, CNN, RNN)<br>- **생성형 AI 모델 이해**: Transformer, GPT, LLM의 원리와 활용<br>- 오픈소스 LLM을 로컬에서 실행해보기 |
| **10주**| **생성형 AI 기반 분석 서비스 기획** | - **프롬프트 엔지니어링 고급**: Few-shot, Chain-of-Thought 등<br>- **RAG (검색 증강 생성) 기초**: 외부 데이터를 연결한 지능형 챗봇 구축<br>- 생성형 AI로 ETL(추출-변환-적재) 과정 자동화 |
| **11주**| **종합 프로젝트 (기획 및 설계)** | - 팀/개인별 프로젝트 주제 선정 (예: 마케팅 데이터 분석, 금융 데이터 예측, 고객 리뷰 분석 등)<br>- 데이터 수집, 분석, 모델링, 서비스 기획 전반 설계 |
| **12주**| **종합 프로젝트 (구현 및 발표)** | - 프로젝트 최종 구현 및 코드 완성<br>- **프로젝트 데모 데이**: 생성형 AI를 접목한 분석 결과 및 서비스 시연<br>- 피드백 및 향후 학습 로드맵 수립 |

### 💡 비전공자 교육 시 핵심 고려사항

*   **이론보다 실습**: 하루 8시간 중 최소 50% 이상은 직접 코드를 치고 데이터를 다루는 실습 시간으로 구성합니다.
*   **생성형 AI를 '조력자'로 활용**: 막히는 부분이나 아이디어가 필요할 때 AI에게 먼저 질문하는 습관을 들여, 스스로 문제를 해결하는 능력을 기릅니다.
*   **프로젝트의 현실성**: 단순한 토이 프로젝트가 아닌, 실제 서비스될 수 있는 수준의 아이디어를 도출하도록 지도합니다.
*   **커뮤니티 형성**: 스터디 그룹이나 멘토링을 통해 비전공자 간의 협업과 동기 부여를 강화합니다.
